工作流复制器


状态：待办
来源：2026-09-02 社区调研
关联：AI工作流学习（独立项目，不合并）


这是什么
这是一个可单独推进、也可以作为 AI 工作流学习的进阶实践方向。目标是把“人先做一遍”变成“AI 学会并以后自动执行”。


和《AI工作流学习》的关系
- 两者关联，但不合并。
- 《AI工作流学习》负责学习工作流基础、节点、触发器、提示词、数据流等。
- 本项目单独研究“从真实操作中学习工作流”的产品与技术路线。
- 以后既可以先学基础再做本项目，也可以直接把本项目作为实践课题推进。


核心形态
开始录制 → 用户正常完成一次任务 → AI 识别固定步骤与变量 → 生成可复用流程 → 下次一句话执行。


后续可扩展
- 失败时 AI 兜底与自恢复
- 步骤可视化、编辑、重放
- 跨网页/跨软件执行
- 自动发现高频重复操作并建议自动化（流程挖掘）


现成基础设施候选
Browser Use / workflow-use / screenpipe / MCP / 本地脚本。原则是优先调研、组合和二开，不从零重复造底层。


待办
- 做专项社区调研：同类项目、成熟度、维护状态、许可证、可二开性
- 拆解 workflow-use 的录制/重放机制
- 评估 screenpipe 是否适合行为采集和流程挖掘
- 选择一个真实重复任务作为 MVP
- 验证“做一遍 → 生成流程 → 重放 → 失败兜底”的最小闭环
