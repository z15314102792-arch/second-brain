### claude-code-remote Windows 兼容修复

重装 claude-code-remote 后需手动改两个文件，否则 Windows 上跑不起来：

**1. `pty-session.js`（路径：`%APPDATA%\Roaming\npm\node_modules\claude-code-remote\dist\pty-session.js`）**
- `isExecutable()` 方法 — Windows 不支持 `fs.constants.X_OK`，改用 `fs.existsSync()`

**2. `tunnel/cloudflare.js`（同目录）**
- `spawn('cloudflared')` → `spawn('cloudflared.exe', ..., { shell: true })`
