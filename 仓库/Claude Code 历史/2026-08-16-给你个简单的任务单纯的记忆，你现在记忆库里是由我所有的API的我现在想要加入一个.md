## 两个要点，你需要知道

**1. 为什么这个 key「只存在这台电脑」**

你的记忆库会自动同步到 GitHub（私有仓库）。key 这种东西一旦上传云端，哪怕仓库是私有的，也有被盗刷额度的风险。所以我把这个文件加进了 `.gitignore`，让它**不跟着 git 走**——和之前 DeepSeek key 的处理思路一致（DeepSeek 的 key 是放在 GitHub 的 Secrets 里，笔记里只记"key 在哪"）。

**2. 一个副作用**

正因为被忽略了，这个 GPT key **不会同步到你的手机和 HDD 备份**，只在这台电脑上。不过你说过现在用不到、只是怕忘，所以这样最安全。

如果哪天你想让它也能跟着备份走，跟我说一声，我可以帮你改放到 GitHub Secrets（和 DeepSeek 一样，云端安全保存，但要找回时多一步去 GitHub 仓库看）。现在这样最省事，够用。
