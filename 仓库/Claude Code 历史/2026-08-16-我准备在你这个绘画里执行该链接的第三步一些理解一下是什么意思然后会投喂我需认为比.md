## 两个功能相近的 skill，我怎么判断用哪个？

**靠每个 skill 自带的"说明书"（description）来判断，谁说得更准、边界更清，就选谁。** 具体分四步：

### 1. 先看谁的 description 更精准命中你的话

每个 skill 都写了一段"我在什么情况下用我"。你说话时，我逐个比对，**最贴合你这句话的那个胜出**。

### 2. 再看边界说明（好的 skill 会写"我不管什么"）

真正好的 skill 会在说明书里写清楚边界，比如 cangjie 就明确写了：

> "NOT for simple summarization（不是用来做简单摘要的）…… role-playing is nuwa-skill's job（角色扮演是 nuwa-skill 的活）"

这种 skill 会自己划清和隔壁 skill 的界线，我一看就知道"这个场景归谁"。

### 3. 看当前场景

你正在做什么、在哪个目录、上一句聊的什么，也会帮我校准。比如你在做网页，网页相关的 skill 天然优先级更高。

### 4. 实在分不清，我会问你，或者先试最接近的那个

如果两个 skill 功能真的高度重叠、说明书也都没写清边界，我不会硬猜——**要么问你一句，要么先跑最相关的那个看结果对不对**。
