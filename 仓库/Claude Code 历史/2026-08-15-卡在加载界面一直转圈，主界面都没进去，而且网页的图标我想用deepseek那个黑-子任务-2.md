# DeepSeek Harness（dsh）插件生态调研报告

## 一、先给结论（一页纸）

1. **官方没有「内置长期记忆」**。dsh 官方把「记忆」定义为**会话日志本身**（事件日志，每轮对话、工具调用、推理过程都存成日志），官方刻意不做 MEMORY.md/USER.md 那种跨会话记忆文件。你要的「跨会话记忆 + 读写外部 markdown」全得靠**社区插件**。
2. **记忆插件里最值得装的是 `dsh-persona-memory`**：它把记忆存成两个可读的 markdown 文件（MEMORY.md / USER.md），并且磁盘格式与另一个 AI 助手 **Pi（Hermes Agent 生态）字节级兼容**——如果你打算让 dsh 和 Pi 用同一套记忆文件，这个插件直接命中。npm 可装，国内直连。
3. **想读写「你自己的 Obsidian 笔记」**：目前没有「一键双向同步」的现成插件。最接近的是 **KnowLP-RAG**（把 Obsidian/任意 markdown 文件夹当知识库，AI 可检索引用，以「读」为主）和官方 `@deepseek-ai/dsh-skill-filesystem`（把外部 markdown 目录当「技能」加载）。**「让 dsh 自动往你的 Obsidian 里写记忆」是市场空白，属于值得做的新插件方向。**
4. **官方 Memory MCP（`@modelcontextprotocol/server-memory`）能接**，但它的记忆存成 **JSONL 知识图谱**（实体/关系/观察），**不是 markdown，也不能指向你已有的笔记目录**。想当「共享 markdown 记忆」用它不合适。
5. **浏览器自动化插件是干嘛的**：让 AI 像人一样打开网页、看内容、点击按钮、填表、抓数据、截图（比如「帮我把这个网页商品价格抓下来存成表格」）。装它需要下载一个浏览器内核（约 400MB，国内可能慢），或复用你电脑上已装的 Edge/Chrome。
6. **给小白的第一建议**：先装 **`dshmarket`**（官方插件市场，装完 Web UI 里出现「Settings → Plugin Market」，之后所有插件都能在里面一键装），再装 **`dsh-persona-memory`** 解决记忆。浏览器插件当第二兴趣装一个试试。

> 澄清一处背景信息：「官方 Web UI 有 Plugin Market 入口」——调研发现 **Web UI 本身不内置**，需要先装 `dshmarket`（或社区替代品）后才有这个入口。

## 二、A. 记忆 / 共享记忆能力（重点）

### A1. 官方内置记忆是什么形态？

- **没有独立的长期记忆系统**。官方仓库讨论 #525 明确：官方刻意**不构建** MEMORY.md/USER.md 这类文件式记忆机制，认为「会话状态就该留在会话日志里」，技能由用户自己编写审核。曾有人把 hermes-agent 的记忆机制移植成插件（`@hyls9527/dsh-memory`），仓库现已**归档停止维护**，作者结论是官方不打算内置。
- 官方文档 `docs/subsystems/session.md`：**会话日志是真源（source of truth）**。所有模型调用、工具执行、fork/resume、压缩、持久化都以「事件日志」形式留存，通过 `deriveMessages()` 派生模型每次看到的上下文。
- 第三方 `dsh-native-memory` 用 DSH 自己的存储域（`~/.dsh/storages/dsh_memory.json`）做**按工作区**的长期记忆，写入需人工审批、有来源溯源——可视为「准官方」风格的记忆插件（但仍是社区插件）。
- 结论：**官方能保证的是「跨会话续聊」（会话日志可 resume），不能保证「AI 自动记住你的偏好」**，后者必须装插件。

### A2. 读写外部 markdown（Obsidian）的插件

| 插件 | 干什么 | 能不能指向你自己的目录 | 安装 | 国内可用性 |
|---|---|---|---|---|
| **dsh-persona-memory** | 跨会话记忆，存成 MEMORY.md（AI 笔记，默认5000字符）+ USER.md（你的画像，默认8000字符），`§` 分隔，每轮注入 | **能**。配置 `dir` 可指向任意目录；若 `~/.pi/agent/pi-hermes-memory` 下有 MEMORY.md 会自动与 **Pi 共享同一份文件**（字节兼容） | `dsh plugin --profile web add dsh-persona-memory` | ✅ npm 直连（npmmirror 同步） |
| **dsh-mneme**（`@modusensus/dsh-mneme`） | 「记忆主权」：SQLite 主存 + **可人工编辑的 markdown 镜像**（preferences.md / projects.md / decisions.md / history.md / summary.md），双向同步，后台自动去重合并（autoDream） | **能**。`memoryDir` 可配置（默认 `~/.dsh/memory`），可指向外部目录；但它是自己的格式，不是直接读写你已有的 Obsidian 笔记 | `dsh plugin --profile web add @modusensus/dsh-mneme` | ✅ npm 直连。**要求 Node 24+**（依赖内置 node:sqlite） |

| **@deepseek-ai/dsh-skill-filesystem**（官方） | 把本地 markdown 目录注册成「技能」让 AI 读取，`customSkillDirs` 把 Obsidian 目录加进去即可，支持 `watch` 实时监听 | **能（作为技能读取）** | npm 官方包 | ✅ npm 直连 |
| **dsh-plugin-long-term-memory** | 长期记忆 + 可把高价值记忆自动沉淀到 `docs/project-context.md` 并**追加到 AGENTS.md** | 能（写入项目文档，正好是 Claude Code 等 agent 也认的约定文件） | npm | ✅ npm 直连 |

### A3. 官方 Memory MCP 怎么接、存哪

- 官方有参考示例 `examples/mcp-memory/mcp-reference-memory.cordis.yml`：
  ```bash
  npm install --global @modelcontextprotocol/server-memory@2026.7.4
  dsh web --patch "$PWD/examples/mcp-memory/mcp-reference-memory.cordis.yml"
  ```
- 通过官方桥接插件 `@deepseek-ai/dsh-mcp-client` 连接，工具以 `mcp__server_memory__*` 形式暴露给 AI。
- **存储**：默认 `$HOME/.dsh-mcp-reference-memory.jsonl`，**是 JSONL 知识图谱，不是 markdown**，路径可用环境变量覆盖。**不能指向你已有的 markdown 记忆目录**。想给小白用，这个 MCP 的价值低于上面几个文件式记忆插件。
- 辅助：`dshx`（`@why913/dshx`）可用 `dshx mcp add` 一键管理 MCP，避免手写 YAML。

## 三、B. 浏览器自动化插件（是干嘛的）

**本质**：dsh 原生只有文件系统/终端/搜索/抓网页能力，**没有「操作浏览器」能力**。浏览器插件补上这块——AI 可以打开真实网页、读内容、点击、填表、滚动、抓数据、截图。对小白的使用场景：「帮我把这个网页打开看看」「把这个商品价格抓下来存成表」「帮我提交这个表单」。

| 插件 | 做法 | 优点 | 风险/注意 | 国内可用性 |
|---|---|---|---|---|
| **@anweat/dsh-browser** | 自带 Playwright Chromium（约400MB），9 个工具（open/click/type/scroll/read/screenshot 等） | npm 可装、自动装内核、可复用系统 Edge（channel: msedge）避免下载 | Chromium 国内下载慢；控制真实浏览器有误操作风险 | ✅ npm 直连，内核下载可能慢 |
| **xylt369/dsh-browser**（含 dsh-tool-browser 等 4 包） | 用你电脑的**真实 Edge 有头窗口**、反检测，SSRF 防护，登录态存 `~/.dsh/edge-profile` | bilibili/知乎等反爬站能打开；复用 Edge 不用下载内核 | 走 GitHub 多包仓库；控制真实浏览器需谨慎 | ⚠️ GitHub 直连 |
| **Lum1104/dsh-browser** | **Chrome 侧边栏扩展**，直接操作你已打开的浏览器标签页，保留登录态；页面转成结构化文本+编号元素，按编号点击 | 隐私好（密码/支付字段始终打码）；复用你日常登录 | 需装 Chrome 扩展 + bridge，走 GitHub | ⚠️ GitHub 直连 |
| **dsh-browser-control** | 走 CDP 协议，复用你日常 Chrome 登录态（复制 cookies 到隔离 profile） | 你已登录的站直接可用 | 复制登录数据涉及隐私；可执行任意 JS | ✅ npm 直连 |
| **dsh-playwright-browser** | Playwright 语义定位、多标签，10 个工具 | 语义定位更稳；无任意 JS 执行 | 需内核或系统浏览器 | ✅ npm 直连 |
| **dsh-tool-browser** | Playwright，默认用系统 Edge（channel: msedge），18 个工具 | 工具最全；Edge-first 国内友好 | 工具多、schema 大 | ✅ npm 直连 |

**给小白的安全提醒**：浏览器插件会让 AI 真的操作你的浏览器——建议只在可信网站用，别让它随便点「付款/删除」按钮；多数插件有权限门/白名单，保持开启。

## 七、F. 给小白的一页纸建议

**现在最值得装这 1–2 个：**

1. **先装 `dshmarket`**（插件市场）——命令：`dsh plugin --profile web add dshmarket`，装完重启 `dsh web`，进「设置 → 插件市场」，以后所有插件点一下就能装。
2. **再装 `dsh-persona-memory`**（记忆）——命令：`dsh plugin --profile web add dsh-persona-memory`。装完它会在每次对话开头自动把记住的「你的偏好 + AI 自己的笔记」读进来，跨会话有效；记忆文件就是 `~/.dsh/memory/MEMORY.md` 和 `USER.md`，你能直接用记事本打开看/改。

**动手前务必检查两件事（否则装了没反应）：**
- **要能敲 `pnpm --version`**：`dsh plugin` 命令内部调用 pnpm。没有就先装：`npm i -g pnpm`（npmmirror 加速）。dshmarket 装好后它能帮你检测/一键配 pnpm。
- **确认 Node 版本 `^22.19` 或 `>=24`**（`node --version`）。装 `dsh-mneme` 需要 Node 24+。
- **让 pnpm 也走国内镜像**：执行 `pnpm config set registry https://registry.npmmirror.com`（否则 pnpm 默认连 npmjs 官方源，国内慢）。npm 包（dshmarket、dsh-persona-memory 等）npmmirror 都有同步，✅ 国内直连；标 ⚠️ 的 GitHub 源插件会卡，建议优先选 npm 版。

**风险是什么：**
- **记忆**：AI 写的记忆偶尔会记错/记过头，插件大多有「写前扫描、字符上限、可人工改文件」保护；定期看看 MEMORY.md 就行。
- **浏览器**：让 AI 操作真实网页有误操作风险（点错按钮、提交表单），只用在你信任的网站；别让它碰付款/删除类操作。
- **插件生态**：dsh 是 0.1.0-rc.6 开发者预览版，插件兼容性随版本可能变动，装前看插件说明的适配版本。
