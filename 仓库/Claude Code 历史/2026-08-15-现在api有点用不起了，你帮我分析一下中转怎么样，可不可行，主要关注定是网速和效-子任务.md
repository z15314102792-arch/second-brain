# AI API 中转站调研报告：面向中国大陆、求「大而稳 + 保真 + 不掺水」的可调 Claude 站

> 调研方式：多轮 WebSearch/WebFetch，重点挖掘 V2EX、linux.do、知乎、GitHub、Product Hunt 及独立博客实测。
> 时间范围：截至 2026-08-15。
> 重要前提：**整个行业里没有任何一家中转站能被公认「绝对稳」**——这是所有社区（V2EX、linux.do）的共识。所谓「大而稳」是相对的、分档次的，且每家都有黑历史或风险点。本报告按「是否值得优先试」给结论，不粉饰。

---

## 一、结论（先说结论）

### 排名建议：最符合「大而稳 + 保真」的档位

| 档位 | 候选 | 一句话判断 |
|---|---|---|
| **T0（企业级、有真公司背书）** | **七牛云 AI（Modelink / qnaigc.com）**、**优云智算（UCloud compshare.cn）** | 有上市/老牌公司主体、国内直连、官方通道，是「大而稳」意义上最接近正规军的选择；缺点是价格偏贵、口碑样本少 |
| **T1（社区口碑最硬的「保真」选择，个人运营但信誉极高）** | **api.oaipro.com（linux.do 创始人「始皇」的站）** | 社区（linux.do 4万+用户）公认「唯一真」的官转，保真+稳，价格≈官方价+手续费 |
| **T2（rate.linux.do 评分前列、贵但稳的社区商家）** | **DuckCoding、ikun（IKunCode）、PackyCode、Cubence** | 口碑「稳、真、贵」，个人/小团队运营，被社区当主力+备份；Cubence 近期差评增多 |
| **T3（全球大站，但大陆直连受限）** | **OpenRouter** | 体量全球最大、极稳，但 Claude/GPT/Gemini 对大陆 IP 封锁，必须挂梯子，延迟高——不符合「国内直连」需求 |
| **不推荐用于生产（大但风险高）** | **OhMyGPT、API2D、PackyAPI** | 用户量大但通道含逆向/掺水风险、无 SLA；PackyAPI 会注入系统提示词，明确不推荐 |
| **疑似自推软文、谨慎对待** | **灵眸AI（lmuai.com / clawapi）、非线智能（nonelinear.com）、二狗API** | 所谓「横评第一名」多为其自家软文，见第三部分实锤 |

### 给用户的落地建议
1. **主力走 T0 企业站（七牛云 AI / 优云智算）**，图的是公司主体 + 国内直连 + 可开票对公，最贴「大而稳」。
2. **保真兜底走 T1（始皇的 oaipro）**，社区口碑唯一的「真」渠道，价格贵但符合你「价格贵一点没关系」的预算设定。
3. **T2 社区商家按 rate.linux.do 评分挑一家当备份**，和主力交叉，防单点。
4. **铁律：任何站都小额充值、随用随充、不要囤大额**（跑路是行业常态）；每月用模型真实性检测工具扫一遍主力站，确认没被掺水。

## 二、候选站逐一档案（结论 + 证据）

### T0-1 七牛云 AI / Modelink（推荐优先试）
1. **站名 + 官网**：七牛云 AI（Qiniu AI）推理服务。接入端点 `https://api.qnaigc.com`（国内）、`https://api.modelink.ai`（海外线路）；官网 https://www.qiniu.com 。文档：https://developer.qiniu.com/aitokenapi/13415/tools-claude-code-router-configuration-instructions
2. **成立/运营时间**：七牛云公司成立于 2011 年（老牌 CDN/对象存储公司，美股 NYSE 上市），AI 大模型 API 是近年新增业务线。
3. **规模证据**：真实上市公司主体（不是皮包站）；提供企业级多模型网关、子密钥、账单监控、对公发票；文档体系完整（七牛官方域名）。
4. **真实口碑**：V2EX 有真实用户实测帖，但口碑两极——有人反馈「总是中断、基本无用状态」「垃圾服务商」，也有人表示「可用但慢」（V2EX 帖 https://global.v2ex.co/t/1176769 ）。注意：七牛官方博客（news.qiniu.com）大量宣传自家服务，属「商家自述」。
5. **Claude 支持**：明确支持 Claude，兼容 Anthropic 原生协议（base_url 指到 `api.qnaigc.com` 即可），并有官方 Claude Code / Router 接入教程；也接 GPT、Gemini、DeepSeek 等。
6. **信息性质**：企业能力 = 官方文档/官网（商家自述，但公司真实性可信）；稳定性口碑 = 第三方实测（V2EX 用户帖，样本少、两极）。

### T0-2 优云智算（UCloud CompShare）（推荐优先试）
1. **站名 + 官网**：优云智算（CompShare），官网 https://www.compshare.cn ，模型 API 文档 https://docs.ucloud.cn/modelverse/
2. **成立/运营时间**：UCloud（优刻得）成立于 2012 年，上交所科创板/港股上市的中立云厂商；优云智算是其 AI 云产品线，属近两年新增。
3. **规模证据**：真上市公司主体；官方文档显示「为 200 多家企业用户提供全球大模型 API 服务」（cc-switch 项目 README 收录，https://raw.githubusercontent.com/kongkongyo/cc-switch/main/README.md ）。
4. **真实口碑**：公开社区的第三方实测帖很少；V2EX 有用户称「国内平台套餐内可用 Claude，但需自己配置模型映射，且官网不再显示具体 Claude 型号，后续不确定」（https://global.v2ex.co/member/janssenkm/replies ）。无跑路/掺假实锤记录（因主体是上市公司，跑路概率低）。
5. **Claude 支持**：官方提供 Anthropic 兼容端点 `https://api.modelverse.cn/v1/messages`，明确写「仅支持 Claude 系列模型」；Claude Code 可通过 Coding Plan 接入。但目前主推 DeepSeek/Qwen 等国产模型，Claude 属「能调但低调」状态。
6. **信息性质**：能力 = 官方文档（商家自述，公司可信）；口碑 = 第三方零星实测，需自己试。

### T1 api.oaipro.com（始皇的站，保真口碑最硬）
1. **站名 + 官网**：OAIPRO，官网 `https://api.oaipro.com`；站长个人页 https://zhile.io
2. **成立/运营时间**：由 linux.do 创始人「始皇」（Neo / zhile，知名开发者，Pandora、ja-netfilter、DeepLX 作者）运营，2024 年起随 linux.do 一起运营至今。
3. **规模证据**：非公司、个人运营，但背靠 linux.do 社区（上线两年注册用户破 4 万、月访问约 850 万次、日活 IP 1 万+，SimilarWeb，来源 https://www.ai-insight.org/reports/linux-do ）。始皇自称「原价买 key 卖 key，纯公益中转」，社区信誉极高。
4. **真实口碑**：linux.do 用户评价「什么中转都是假的，只有始皇是真的」「oai pro 的信誉可以直接入」「用始皇的爽」「claude code 分组确认真，保真没有奇奇怪怪问题」。无跑路记录（跑路案例都是别的二道贩子，见第四部分）。缺点：价格≈官方原价+手续费，且是额度制，不便宜。
5. **Claude 支持**：支持 Claude 全系 + Claude Code；默认把 Claude 转成 OpenAI 格式，也支持 Anthropic 原生格式。
6. **信息性质**：**第三方社区口碑为主**（linux.do 大量真实用户帖），可信度高。来源：https://linux.do/t/topic/125092 、 https://linux.do/t/topic/1906789 、 https://linux.do/t/topic/474059

### T2 DuckCoding / ikun / PackyCode / Cubence（rate.linux.do 前列，贵但稳）
1. **站名 + 官网**：均为个人/小团队运营，官网域名需到 rate.linux.do 商家页或 linux.do 帖子内确认（本报告未取得可信的官网 URL，不臆造）。别称「鸡鸭鹅农」：ikun=鸡、DuckCoding=鸭、Cubence=鹅（原 shareyourcc）、PackyCode=农。
2. **成立/运营时间**：约 2024-2025 年兴起，持续运营 1 年以上（社区讨论从 2025 年延续至今）。
3. **规模证据**：个人运营为主；DuckCoding 有服务状态页、GitHub 代码开源、微信/QQ 售后群，被评价「不像三个月跑路的野鸡站」。评估可看官方评分站 rate.linux.do。
4. **真实口碑**：
   - **DuckCoding**：「稳定性和可靠性（不掺水）上最优」「稳得没话说」，唯一一次周四晚炸了约 20 分钟；缺点贵（有用户称 400 块用一周）。来源 https://linux.do/t/topic/1116047 、 https://gist.github.com/rjao18/9bb308087f0bcda1099840bdb47be945
   - **ikun**：「贵但稳」代表，客服响应好；近期因外部因素略有波动。来源 https://linux.do/t/topic/1519094
   - **Cubence**：早期口碑最好（缓存命中率 90%+、封号潮第一批恢复），但 2025 年底-2026 年差评增多：延迟高、倍率不透明、客服差、越来越贵。来源 https://linux.do/t/topic/2268392 （避雷帖）、 https://linux.do/t/topic/1348751
   - **PackyCode**：技术好、诚实、出新渠道快，长期主力。来源 https://linux.do/t/topic/1116047
5. **Claude 支持**：全部支持 Claude + Claude Code（CC 中转是它们主业）。
6. **信息性质**：第三方社区口碑（linux.do 多帖交叉），可信度较高，但均为个人运营，跑路风险客观存在。

### T3 OpenRouter（全球最大，但大陆直连受限，仅作参考）
1. **站名 + 官网**：OpenRouter，官网 https://openrouter.ai
2. **成立/运营时间**：2023 年创立，全球最大的模型聚合平台之一，运营多年。
3. **规模证据**：全球用户量巨大，Pass-through 定价，与官方同价；投资/运营主体为美国公司。
4. **真实口碑**：全球口碑极佳、稳定、低延迟，是「大而稳」的国际标杆。但 linux.do 实测：**OpenRouter 对 Claude/GPT/Gemini 做了大陆 IP 封锁**，返回 403「This model is not available in your region」，大陆 IP 只能用国产模型；需海外 IP（挂梯子）才可调 Claude。来源 https://linux.do/t/topic/1846933 、 https://linux.do/t/topic/1754552
5. **Claude 支持**：支持 Claude（直通官方价）+ Claude Code，但大陆直连不行。
6. **信息性质**：第三方实测（linux.do）+ 全球公认，证据充分。

### 大但风险高：OhMyGPT / API2D / PackyAPI（不推荐作主力）
1. **OhMyGPT**（https://ohmygpt.com ，约 2025-08 起运营）：聚合 260+ 模型、便宜（官方 1/5 左右）、国内支付方便，个人开发者口碑不错；但**底层通道「官方与逆向混合」、无 SLA、实测可用性约 95%**，被实测到「挂 Opus 4.1 名、回 Opus 4 结构」的版本漂移，企业级测评结论是「个人可用，别上生产」。来源 https://adg.csdn.net/694cf5905b9f5f31781aabac.html 、 https://segmentfault.com/a/1190000047942701 、 https://lmspeed.net/zh/provider/www-ohmygpt-com
2. **API2D**（https://api2d.com ，老牌、2023 年起）：国内最早一批 GPT 中转，口碑「老牌稳定」，但**主要是 GPT 系列，Claude 支持弱、模型更新慢**，高并发弱（5000 并发丢包 0.45%）。无跑路记录。来源 https://juejin.cn/post/7604666872127766547 、 https://virtualcardx.com/2026/07/05/china-api-proxy-list/
3. **PackyAPI / PackyCode**（官网 https://www.packyapi.ai ）：争议最大——横评指出其低价来源是**逆向接口（反代 Cursor/Kiro/GitHub Copilot）**，会**注入 Cursor/Kiro 内置系统提示词**、不支持 Prompt Caching、Anthropic 收紧接口会成片失效。另有一篇 gist 评测却高度好评（文档清晰、客服快）。信息互相打架，属高风险。来源 https://raw.githubusercontent.com/LMU-AI/claude-api-relay-review/main/README.md 、 https://gist.github.com/jhw26717/55af3992134055cedcbb3049b22d3d0a

## 三、明确的软文 / 自推信号（重要，务必警惕）

### 1. 「8 个 Claude API 中转站横评」系列 = 灵眸AI 自推软文（实锤）
- 同一篇内容在 **GitHub 仓库 `LMU-AI/claude-api-relay-review`、阿里云开发者社区、腾讯云开发者社区** 等渠道重复发布，作者一致。
- **决定性证据**：仓库组织名 **LMU-AI** 与榜首站 **灵眸AI（lmuai.com）** 完全同名（LMU-AI = lmuai）；文中给了自己站 **5 星第一**，并夹带**带返利参数的注册链接** `https://clawapi.fulitimes.com/register?ref=vJaWWr4T`（ref= 是典型分销返利标识）。
- 结论：**判定为自推软文**，文中所有价格/稳定性数据不可采信。来源 https://github.com/LMU-AI/claude-api-relay-review 、 https://cloud.tencent.cn/developer/article/2657042

### 2. 非线智能（nonelinear.com）= 商家自述 + 付费推广（疑似软文）
- 大量内容来自**自家官方博客 blogs.nonelinear.com**，关键词全是「非线智能 API 首选」；另见齐鲁网财经（caijing.iqilu.com，常见广告软文渠道）和部分 SegmentFault 文章。
- 宣称「99.99% SLA、485 模型、100% 官方通道、Claude Code 零适配」——**全部为平台自称**，缺乏独立第三方交叉验证。该公司主体是否真实存在、是否真有官方通道，未查到独立证据。
- 结论：**疑似软文，需交叉验证**，不可直接采信其「企业级」卖点。来源 https://blogs.nonelinear.com/blog/ai-llm-api-key-nonelinear-api-proxy-b4d2b0a8cd83 、 https://caijing.iqilu.com/cjzx/2026/0722/5930784.shtml 、 https://segmentfault.com/a/1190000047804837

### 3. 二狗API（Product Hunt）
- Product Hunt 上以「绝不掺水」为卖点的站（https://www.producthunt.com/p/api-codex-cc ），上线时间短、无社区口碑样本，属**商家自述**，建议观望。

### 4. 优云智算/UCloud 相关推广文
- 多篇「企业级选型指南」软性推荐优云智算，多为付费推广稿；但公司本身是真实的（UCloud 上市），与纯皮包站不同。主体可信、宣传需打折。

## 四、行业性黑历史与共性风险（所有站都要知道）

1. **掺水/模型掉包是行业重灾区**：《每日经济新闻》等报道，第三方对 17 个主流平台测试，**45% 存在「身份不匹配」欺诈**（收 Claude/GPT 的钱、背后跑国产模型）。来源 https://stcn.com/article/detail/3905001.html 、 https://m.huxiu.com/article/4857684.html
2. **跑路 / 卷款案例（社区点名）**：
   - **88code**：极不稳定、退款拖延、「捂嘴踢人」（https://global.v2ex.co/t/1184117 、 https://linux.do/t/topic/1584743 ）
   - **unity2.ai / gpt2share**：被称「跑路惯犯」（https://global.v2ex.co/t/1227344 ）
   - **ShawnAPI**：疑似跑路（https://linux.do/t/topic/774272 ）
   - **opusrelay.com**：被曝掺 DeepSeek、客服拉黑用户（https://linux.do/t/topic/2515596 评论区）
   - **老虎中转**：个人收款、同源事件（https://linux.do/t/topic/1685859 ）
   - **privnode**：口碑冲突——一处称「稳但贵」，rate.linux.do 帖称「疑似卷款跑路」，需自行核实。
3. **监管收紧**：2026 年 4 月、6 月国安部两次发文提示中转站安全风险；2026-05 已有站长因非法经营罪被刑拘；83% 新增服务商无 ICP 备案，2026-06-30 未备案将被停止访问。来源 https://finance.sina.com.cn/jjxw/2026-07-25/doc-iniixwvs9224710.shtml 、 https://segmentfault.com/a/1190000048070588
4. **假缓存是隐形烧钱坑**：不支持真 Prompt Caching 的中转，成本比正常高 4 倍以上。来源 https://global.v2ex.co/t/1208975
5. **「便宜+快+真」不可能三角**：社区共识，越接近官方价越稳；1 元 1 刀的站几乎必然掺假。来源 https://linux.do/t/topic/1220071 、 https://global.v2ex.co/t/1209400

## 五、结论复核清单（给用户自测）
- 每月用模型真实性检测工具（如社区开源的 Claude 真实性检测）扫一遍主力站；
- 任何站只小额充值，不囤大额；
- 主力（T0）+ 保真兜底（T1）+ 社区备份（T2）三者搭配，谁不稳切谁。
