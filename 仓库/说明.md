# 仓库（这里放什么）

> 导航：[回到总索引 [[MEMORY]]]

放**废弃的、备份的、历史基线**。不常用了，但先留着不删。

## 装什么

- 不玩了/废弃的项目（比如废弃的游戏、旧版原型）
- 备份的历史版本、基线
- 历史会话存档 → 子目录 `仓库/Claude Code 历史/`

## 怎么判断

问自己：**「这个还用吗？不用了但舍不得删？」**

- 不常用、但先留着 → 放这里
- 确认彻底没用了 → 放 [[_垃圾站/说明]]，不是这里

## 和别的目录的区别

- **仓库 vs 项目**：还在做/刚做完 → [[项目/说明]]；废弃不玩了 → 仓库
- **仓库 vs 垃圾站**：仓库 = 留着备用；垃圾站 = 确认没用、准备删
