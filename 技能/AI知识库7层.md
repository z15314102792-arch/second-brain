# AI 知识库 7 层阶梯

> 来源：抖音博主「姜胡说」《从零搭建AI知识库》（2026-08-19 喂入）
> 适用：判断「我的知识库搭到第几层、下一步该做什么」时调用。
> 与 [[技能/AI知识库四步闭环]]（怎么喂）、[[技能/PARA知识库方法]]（第4层的细节）配套。

## 为什么必须搭 AI 知识库（元认知）

- **元认知** = 发现自己问题、调整自己思考过程的能力。人最大的问题是「发现不了自己的问题，发现了也不知道怎么改」。
- **AI 是元认知的保证**：只要如实呈现，AI 能每天/每小时/每分钟发现你的问题、给你选择，让你看到自己「可能要犯错」。
- **信息差机会**：真正付费长期用 Agent 的人极少（约 1:10000），早做就是机会。

## 7 层阶梯（从低到高）

| 层 | 名称 | 做什么 | 性质 |
|----|------|--------|------|
| L1 | 对话查询 | 当搜索引擎用，给思路 | 消费 |
| L2 | Agent 干活 | 订票/生图/写文案，单任务自动化 | 消费 |
| L3 | 从做到造 | 重复做一件事，告诉 AI「你是谁、你做什么」（写进 CLAUDE.md / MEMORY.md） | **创造起点，90% 人卡这层** |
| L4 | 结构化目录 | PARA 分门别类（项目/资产/资源/归档） | 创造 |
| L5 | 索引定位 | 几百个文件时建索引目录，AI 自己查 | 创造 |
| L6 | 语义搜索 | 上千文件时用向量搜索，说意思 AI 自动找相近 | 创造 |
| L7 | 自动赚钱 | 知识拆成「原子」，按问题排列组合解决 | 变现 |

## 核心一句话

> **知识只要有用，就一定能赚钱。** 方法：发现用户高频问题 → 从知识库找「原子」（单个可独立解决问题的小知识单元）→ 排列组合正好解决 → 发布/交付。

## 什么时候取出来用

- 用户问「我知识库搭得对不对/下一步干什么」→ 拿 7 层对照，标记已完成/进行中/未开始。
- 用户纠结「要不要上向量搜索/重工具」→ 看文件量：大几十/上百个文件才需要 L5 索引，上千才需要 L6 语义搜索，别提前。
- 用户复盘时 → 用「元认知」视角：让 AI 发现用户自己发现不了的问题（接四步闭环第 4 步）。
