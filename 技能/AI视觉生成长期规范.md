# 定位与触发

本规范来自“100个优秀AI图片生成指令”的调研，以及随后重做的“100个非官方、多样化AI短剧/视频实战指令”调研。图片部分保留首轮有效规律；视频部分以个人创作者、社区实测、独立开发者与开源案例库为主要证据，覆盖多模型、多工作流和多种镜头用途。这里固化的是跨样本可复用的结构、约束方式和失败预防方式，不把案例机械拼成模板。

以后凡是涉及AI短剧、角色图、场景图、道具图、分镜图、Storyboard、Start Frame、图生视频、文生视频、镜头提示词、视频素材提示词、镜头返工等任务，默认先调用本规范，不从零开始重新发明提示词。只有模型能力、平台语法、题材目标或用户明确要求与本规范冲突时，才做针对性偏离，并说明原因。

# 总原则

原则一：先解决“必须正确”，再解决“是否好看”。人物身份、场景结构、空间关系、动作逻辑、时间顺序、镜头关系属于硬约束；氛围、质感、色调、电影感属于软约束。硬约束失败时，画面再漂亮也视为失败。

原则二：把可控变量拆开写，不把所有要求揉成一段形容词。人物、场景、空间、机位、动作、光线、风格、输出规格、负面约束分别承担不同职责。

原则三：参考图必须“职责分离”。角色参考只负责人物身份，场景参考只负责空间与家具，风格参考只负责视觉语言；明确写出“不继承什么”，防止模型把参考图里的无关人物、服装、构图或物体一并复制。

原则四：一镜头一主要意图。单张图只承担一个静态瞬间；单个短视频镜头通常只承担一到两个主要动作。复杂事件拆镜头，不靠超长提示词强迫模型一次完成。

原则五：优先正向描述目标，再追加针对性的负面约束。负面约束用于封堵已知高风险错误，不用于堆几十条泛化禁令。

原则六：生产型任务中，一致性优先于新奇。已经锁定的人物、服装、场景结构、道具和风格，不因为“更好看”就随意重设计。

原则七：提示词追求“最小充分信息”，不是越长越好。任何句子都应回答：它控制了哪个可见变量？不写会产生什么具体歧义？如果答不出来，就可能是噪声。

原则八：平台参数和语法只在确认模型后使用。默认先写平台无关的自然语言核心，再针对Midjourney、GPT Image、Imagen、Flux、Runway、Veo、Kling、Sora等模型做适配，避免把某个平台的技巧误当通用规律。

原则九：失败后先判断错误属于哪一层，再返工。人物身份、空间结构、机位、动作逻辑等结构性错误，应从固定母版重新生成；不要在错误底图上无限补丁式修改。

# 图片生成规范

图片提示词的本质是：把“一个静止瞬间里什么必须存在、位于哪里、从哪里看、看起来怎样”描述清楚。

## 推荐顺序

第一层：任务与参考图职责。先说明要生成什么画面，并逐张规定参考图只负责什么、禁止继承什么。

第二层：人物身份锁定。写明必须继承的人脸特征、年龄感、发型、服装、体态等稳定身份信息；已经锁定的角色不重新设计五官。

第三层：场景与道具。写清空间类型、固定家具、门窗、桌椅、道具以及需要保持的结构关系。

第四层：空间关系。明确人物相对桌子、门、窗、其他人物和镜头的位置。优先使用“入口这一侧、长边座位、靠窗、偏远端、画面左/右、前景/中景/后景”等可验证关系，而不是“坐得自然”“在旁边”等模糊词。

第五层：机位与构图。至少说明景别、摄影机所在方向、视角高低、正侧关系和主体在画面中的位置；需要时再补焦段感、透视和景深。

第六层：姿态、动作、表情与视线。静态图只描述能被冻结在一个瞬间的姿态。人物的手、身体朝向、头部朝向、视线目标分开写，避免“看着某人但身体又完全背对”等冲突。

第七层：光线、色彩和材质。说明光源方向、软硬、时间感、主色温、材质质感。它们服务于已经正确的构图，不应覆盖人物身份和场景结构。

第八层：风格。把“二维写实动漫、电影感、手绘感、纪录片感、真实摄影”等放在结构之后。风格是渲染层，不是空间和身份层。

第九层：输出规格。明确横竖画幅、比例、是否单人、是否允许文字、是否要求背景完整等。

第十层：负面约束。只写最可能发生且代价高的错误，例如“不增加新人物、不改变服装、不把人物放到桌子正中、不继承场景参考图中的人物、不新增随身物”。

## 图片硬约束优先级

人物数量与身份 \> 场景结构 \> 人物空间位置 \> 机位与景别 \> 动作与视线 \> 服装道具连续性 \> 光线 \> 风格与氛围。

## 图片常见失败与对应防法

身份漂移：不要只写人物名字，要写参考图职责与不可变身份特征；明确“保持原有五官比例，不重新设计”。

参考污染：明确“参考图1只用于人物，参考图2只用于空间，不继承其中人物/构图/服装”等职责边界。

空间放错：不要只写“坐在桌边”。把桌子的长边/短边、入口侧/远端、靠窗/靠门、画面左右写清楚。

机位歧义：不要只写“侧面拍摄”。写摄影机位于哪里、相对主体朝向、视线轴线以及景别。

物体凭空增加：列出允许存在的关键物品，并明确“不新增配饰、随身物、第二个杯子”等高风险对象。

风格压过身份：先锁角色和构图，后写风格；必要时写“风格化不改变面部结构和年龄感”。

过度复杂的手部动作：如果手不是剧情重点，减少手指级动作描述；如果是重点，则把动作拆清楚并保证画面可见。

提示词过载：当一张图同时要求多人物互动、多个动作、复杂景深和大量道具时，优先拆镜头，不继续加形容词。

## 图片生成前自检

检查人物数量是否明确；参考图职责是否逐张定义；角色不可变特征是否锁定；空间位置是否能画成平面关系；摄影机位置是否明确；动作和视线是否互相兼容；场景固定物是否完整；是否存在互相冲突的描述；负面约束是否针对真实风险；整段提示词是否只描述一个可冻结的瞬间。

# 视频/短剧镜头生成规范（V2｜非官方实战样本修订）

## 证据基准

本节以新版100个非官方、多样化实战样本为主要依据：个人创作者、社区实测、独立开发者与开源案例库；模型官方示例不计入这100个核心样本。样本覆盖多种模型、图生视频/文生视频/多参考图/首尾帧/对话与原生音频/循环/VFX/广告/动漫/UGC等用途。以下结论只固化跨样本稳定规律，模型专属语法仍需按平台适配。

## 核心认识

第一，视频Prompt没有“越短越好”或“越长越好”的统一答案。真实成功案例同时存在一句话出片和数千字符分区控制。提示词长度应由任务复杂度、输入方式和模型控制能力决定。  
第二，视频Prompt的核心不是描述画面有多漂亮，而是描述“时间里发生什么变化”。主体运动、摄影机运动、场景运动、声音变化是主要控制对象。  
第三，首帧/参考图本身就是控制系统的一部分。构图不给运动留空间时，Prompt很难补救。例如需要拉远却把人物塞满画面，需要横移却没有对应方向的负空间，应先重做Start Frame，而不是继续烧视频额度。  
第四，真实创作者普遍依赖迭代，而不是迷信一次命中。失败后应做“补偿式修正”：针对模型反复犯的一个具体错误增加一条明确约束，而不是把整段Prompt无限加长。  
第五，精确复现不能只依赖文字。相同Prompt仍可能产生不同结果；角色一致性、构图和特定运动越重要，越应该依赖参考图、首尾帧、固定资产和模型可用的种子/引用机制。

## 三档Prompt写法

轻量镜头：适合单主体、单动作、5—10秒左右的简单镜头。优先写“景别/机位 \+ 主体 \+ 一个主要动作 \+ 一个主要镜头运动 \+ 必要的风格或声音”。不要为了显得专业加入大量镜头品牌、焦段和形容词。  
标准图生视频镜头：适合AI短剧常规镜头。结构为“保持项/参考锁定 → 主体动作变化 → 摄影机运动 → 必要的环境次级运动 → 连续性与物理约束 → 结束状态 → 必要的声音 → 针对性负面约束”。  
结构化复杂镜头：适合多参考图、10—15秒复杂表演、广告、对话、原生音频、首尾帧、无缝循环或模型明确支持复杂指令的情况。可使用清晰分区，例如\[FORMAT\]、\[REFERENCE LOCK\]、\[ACTION/TIMELINE\]、\[CAMERA\]、\[AUDIO\]、\[CONTINUITY\]、\[END/LOOP\]。分区的价值是消除职责混淆，不是让Prompt看起来更复杂。

## 先判断生成模式

文生视频：需要提供足够的主体、场景和初始构图信息，再重点描述动作和镜头。  
图生视频：首帧已经确定的身份、服装、场景和构图不重复大段重述；重点写“保持什么 \+ 改变什么”。  
多参考图：逐张分配职责，例如图1负责人物身份、图2负责场景、图3负责道具或服装，并明确禁止交叉污染。  
首尾帧/过渡：明确起点、终点和中间变化路径；不要只描述终点效果。  
无缝循环：除了动作，还要明确结尾如何回到与开头兼容的状态，避免最后一帧无法闭环。  
视频延长：把已有片段最后状态当作新的起点，只描述接下来新增的变化，避免重新设定人物和场景。

## 动作与时间

一个镜头默认只保留一个核心行为链。两个到三个物理上连续的微动作可以共存，例如“停顿—抬头—看向门口”；涉及大幅位移、复杂交互、多个剧情信息点时优先拆镜。  
动作使用可见动词，不用情绪形容词代替行为。“紧张地行动”不可执行；“手指停住，抬眼看向门口，呼吸变浅”才可执行。  
简单镜头优先自然语言顺序“先—随后—最后”。只有模型确实支持且镜头复杂时才使用时间码/时间段，不把时间码当作所有模型的通用技巧。  
动作必须存在连续路径。坐到站、拿起物体、转身离开等都要符合身体和物体的物理过程；如果模型难以完成，拆镜比继续加描述更有效。

## 三种运动必须分开

主体运动：人物、动物、车辆或主要物体如何移动。  
摄影机运动：静止、推、拉、摇、移、跟随、环绕、升降、手持漂移等；写清方向、速度和幅度。  
场景运动：风、窗帘、烟尘、灯光、背景人群等次级变化。  
不要用“dynamic motion”“cinematic movement”等模糊词同时指代三者。一个短镜头通常只保留一个主要摄影机运动，其他运动作为弱辅助。

## Start Frame与运镜匹配

运镜必须在生成图片阶段提前设计。要拉远，需要画面之外有可合理补全的空间；要向左横移，首帧右侧主体与左侧负空间要给模型留出运动余量；要环绕，人物与场景必须具备足够稳定的三维关系。  
如果首帧空间设计与目标运镜冲突，优先重做首帧。不能把“构图错误”伪装成“Prompt问题”。

## 参考图与一致性

角色参考优先锁定身份、面部比例、年龄、发型、服装和体态；场景参考锁定几何结构、门窗和固定家具；道具参考锁定形状、材质与持有关系。  
多参考图必须明确每张图“负责什么”和“不负责什么”。复杂模型允许长Prompt时可以使用REFERENCE LOCK一类分区；普通模型则用简短自然语言完成同样职责。  
图生视频不要因为追求更漂亮而重新描述一个不同版本的人物。运动越复杂，越要减少无关的重新设计要求。

## 对白与声音

模型支持原生音频时，把声音作为独立控制层：谁说话、说什么、说话顺序、语气/口音、环境声、关键音效和音乐分别描述。  
对白用明确说话者和引号区分，双人对话尤其要避免“声音要求”和“人物动作”混成一长句。  
需要口型同步时，让台词长度与镜头时长匹配；短镜头不要塞过多对白。  
模型不稳定或不支持音频时，不强迫视频模型同时解决声音，改为后期配音/音效。生产稳定性优先于“一次生成全部”。

## 连续性与负面约束

优先锁定人物身份、服装、场景几何、关键道具的位置/持有关系和光线方向。  
负面约束只针对高概率、高代价或已经真实发生的错误，例如“不新增车门”“人物保持原位，只有摄影机前推”“不要出现第三人”。社区实测表明，针对反复错误的补偿式描述比泛化的几十条禁止词更有价值。  
技术品牌、摄影机型号、8K等词属于软风格信号，除非模型对其有稳定响应，否则不能当作结构控制手段。

## 结束状态与循环

常规镜头写清最终姿态、视线、人物所在位置以及镜头最后是否停住，避免动作做过头或尾帧随机漂移。  
需要接下一镜时，终态要服务剪辑衔接；需要首尾帧或循环时，终态必须满足下一状态/开头状态的几何和动作条件。

## 失败诊断顺序

第一查输入资产：首帧、参考图、角色/场景母版是否本身就与目标冲突。  
第二查核心动作：是否一次要求过多动作，或动作不可见、不可连续。  
第三查镜头语言：摄影机运动是否具体，是否与主体运动混淆。  
第四查连续性：是否有身份漂移、道具瞬移、场景重构、额外人物或物体。  
第五查节奏与声音：时间分配、对白长度、声音来源是否合理。  
最后才查风格词。结构错误不能靠“更电影感”修复。

## 视频生成前自检

先确认这是文生视频、图生视频、多参考、首尾帧、延长还是循环任务；确认一个镜头只有一个核心意图；确认首帧为目标运镜留出了空间；确认主体/摄影机/场景三种运动已分开；确认动作存在清晰起点、路径和终点；确认参考图职责没有污染；确认声音是否真的需要模型原生生成；确认负面约束只针对真实风险；确认模型是否真的支持时间码、复杂分区或多参考控制；确认失败时可以明确知道应该修哪一层。

# 短剧生产中的调用方式

剧本场景先拆成Shot List，再为每个镜头单独生成提示词。不要把整段戏直接交给视频模型。

角色、场景和道具先有固定母版，再做正式剧情镜头。正式镜头从母版重新生成，不在同一张错误图上无限修改。

图片阶段先把人物、空间、机位和构图定对，再花视频额度。视频模型主要负责“时间变化”，不负责重新设计已经锁定的角色和场景。

结构性错误返工顺序：先检查参考图职责，再检查硬约束，再检查机位/空间，再检查动作，最后才检查风格。如果前三层错误，不做局部美化，直接重新生成。

生成后审片按错误类型记录：身份、场景、空间、机位、构图、动作、物理连续性、光线、风格、技术瑕疵。下一次提示词只修真正出错的层，不无脑增加描述。

# 默认提示词骨架

图片核心骨架：任务目标 → 参考图职责 → 人物身份锁定 → 场景与空间关系 → 机位/景别/构图 → 姿态/表情/视线 → 光线/色彩/材质 → 风格 → 输出规格 → 针对性负面约束。

视频核心骨架不是固定一条。简单T2V：机位/主体/核心动作 → 主要运镜 → 必要风格/声音；常规I2V：保持项/参考锁定 → 动作变化 → 运镜 → 次级运动 → 连续性/终态 → 声音 → 针对性负面约束；复杂多参考/对话/循环：按FORMAT、REFERENCE、ACTION/TIMELINE、CAMERA、AUDIO、CONTINUITY、END/LOOP分区。

这些骨架是按任务选用的检查框架，不是要求每次逐项写满。没有实际控制价值的项应省略，也不要为了“专业感”强行拉长Prompt。

# 生成前总检查

是否已经读取当前项目有效设定和母版；是否把“必须正确”和“可以自由发挥”分开；是否存在参考图职责污染；是否出现互相矛盾的空间或动作指令；是否把人物运动和镜头运动混在一起；是否要求一个镜头承担过多事件；是否用了大量无法验证的形容词；是否为了追求电影感而牺牲人物/场景连续性；是否根据实际模型调整语法；是否能明确判断生成结果“对还是错”。

# 允许偏离的情况

实验性视觉、故意超现实、梦境、抽象转场等镜头可以主动放宽物理连续性；模型明确不支持某类控制时可简化规则；用户明确要求重新设计角色或场景时，可以解除相应身份锁定。任何偏离都应是有目的的，不是因为忘记规则。

# 长期执行要求

以后生成图片或视频提示词时，不再从空白开始。先调用本规范，再读取当前项目中与该镜头直接相关的角色母版、场景母版、道具母版、Shot List和已确认视觉风格，然后只补充该镜头新增的信息。

如果新一轮真实生成结果证明某条规则无效、模型能力发生明显变化，或出现稳定的新失败模式，应更新本规范，而不是在单个会话里临时修补后丢失。

本规范的目标不是让提示词看起来专业，而是提高一次生成命中率、角色和场景一致性、镜头可控性，并降低无效抽卡和视频额度浪费。
