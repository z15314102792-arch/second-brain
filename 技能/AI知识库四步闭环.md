# AI 知识库四步闭环

> 来源：抖音博主「姜胡说」《零基础搭AI知识库，四步闭环越用越聪明》（2026-08-16 喂入）
> 适用场景：想用 AI 系统化学习 / 沉淀知识时，套这套流程。

## 四步闭环

1. **工具准备**：先用已有可用工具，不纠结 Claude Code / Codex。
   - WorkBuddy = 腾讯 AI 办公 Agent，用户**已装** v5.3.11（见 [[资料/WorkBuddy]]）；但它会消耗积分，不再视为默认免费下级。省额度任务优先用 Gemini 或明确免费的模型。
   - 视频里「Coder Work」应为 **CodeBuddy**（腾讯编程助手）的语音误读。
2. **建档案**：告诉 AI 你是谁、干嘛的、优缺点、目标、卡点，让它记住你，以后按你的情况给建议。
3. **喂内容**：好文章复制给 AI、好视频发链接，说「这好在哪」，让 AI 拆「现在能用 vs 未来能用」——能用的列一二三照做，不能用的存成知识块。
4. **每天复盘**：告诉 AI「我是这么用的、结果这样」，让它复盘并给下一步改进。

## 核心心法

- **收藏是心理安慰，喂给 AI 才是落地**：收藏 = 假获得感，拆解 = 真行动。
- **先用起来，别先学会再用**：打球是先上场，不是看十年教学视频再上场。边学边用。
- **够用就好，别囤工具**：纠结工具本身就是在「用准备逃避开始」。

## 什么时候取出来用

- 用户学习任何新领域 / 新工具时，套这个四步：建档案 → 喂内容 → 复盘。
- 用户想囤工具、纠结「先学哪个」时，提醒「够用就好，先用起来」。
- 用户收藏一堆东西不行动时，提醒「别收藏，喂给 AI 拆解」。
