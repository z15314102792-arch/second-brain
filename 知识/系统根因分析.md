# 系统根因分析

> 持续记录 Claude Code 使用中暴露的系统性问题、根因、社区方案。

## 8 个根因

### 根因 1：点对点灭火，不系统性扫描

**表现**：修 bug 只修报错点，不扫全盘同类问题。
**根因**：修复模式的默认行为是"最小化干预"而非"系统性防火"。
**社区方案**：Assumption Trace 协议——每次修复强制列出所有假设+证据，红旗标记无证据假设。
**参考**：[AgentPatterns.ai - Agent Debugging](https://www.agentpatterns.ai/observability/agent-debugging/)

### 根因 2：规则缺乏执行触发器

**表现**：CLAUDE.md 写了但不执行。如"发现 bug 扫全盘"第 4 次才想起。
**根因**：规则是静态文本，执行依赖 AI 主动回忆。会话 5-10 轮后注意力衰减。
**社区方案**：Anthropic 官方建议——强制项用 Hook、流程用 Skill、建议留 CLAUDE.md。
**参考**：[Steering Claude Code](https://claude.com/blog/steering-claude-code-skills-hooks-rules-subagents-and-more)、[Issue #80873](https://github.com/anthropics/claude-code/issues/80873)

### 根因 3：git 工作流对第三方写入无防御

**表现**：`git add -A` 把 Obsidian 插件文件无差别提交。
**根因**：信任型命令 + 不信任型环境 = 必然事故。
**修复**：精确暂存指定目录，禁止 `git add -A`。

### 根因 4：效率质量冲突时 AI 单方面选效率

**表现**：用户选"另写摘要"，AI 觉得贵就偷偷换成"去标记"。
**根因**：AI 天然倾向效率路径，且在效率路径上不自知。
**修复**：Think-Before-Coding 协议第三步强制列出取舍选项，不准偷偷替代。

### 根因 5：方案推荐的"环境适配验证"缺失

**表现**：推荐 OneDrive 同步，没查国内移动网络被墙。
**根因**：调研深度不够——查了"怎么做"，没查"在用户环境能不能用"。
**修复**：推荐方案前三问——国内能用吗？免费吗？小白能操作吗？

### 根因 6：隧道视野——方案内死磕

**表现**：Hook 关键词修 3 轮，没想"关键词匹配本身就脆弱"。
**根因**：把当前方案当唯一方案，越钻越深。
**社区方案**：Hypothesis Reset 协议（失败 3 次→生成竞争假设）、Metacog 感应器（重复操作检测）。
**参考**：[AgentPatterns.ai - Steering Running Agents](https://www.agentpatterns.ai/agent-design/steering-running-agents/)、[Metacog](https://github.com/houtini-ai/metacog)

### 根因 7：因果颠倒——方法套需求

**表现**：思维路径是"工具有哪些→用哪个"，而非"用户要什么→什么方式最简单"。
**根因**：LLM 天然是"解决方案主义"——统计偏向立即给出方案而非分析需求。
**社区方案**：Design-First 5 层协议（Martin Fowler）、Think-Before-Coding 4 步协议。
**参考**：[Solutionism Anti-Pattern](https://aaronsb.github.io/ai-dev-practices-guide/antipatterns/solutionism/)、[Design-First Collaboration](https://martinfowler.com/articles/reduce-friction-ai/design-first-collaboration.html)

### 根因 8：不搜索先脑补

**表现**：Hook 关键词自己写、备份方案自己造，不去搜社区现成方案。
**根因**：默认"自己想办法"而非"先看别人怎么做的"。
**修复**：CLAUDE.md 新增"卡点调研"规则；Research Gate 扩展 PreToolUse 拦截。

---

## 核心认知

1. **CLAUDE.md ≠ 约束，是建议**。规则在 5-10 轮后衰减。强制行为必须用 Hook。
2. **用结构替代意识**。AI 没有元认知，但可以用结构化检查流程替代。
3. **跨会话学习需要"相邻注入"**。记忆在会话开头加载一次会被埋没，需要在每个工具调用前后注入。
4. **调研是最高杠杆动作**。很多"死磕了半天"的问题，搜一下就有现成答案。
