## 关键决策

1. **不按目录隔离**：用户记不住项目路径，与使用习惯冲突
2. **不分级 CLAUDE.md**：没必要，项目身份只需 3 行
3. **不是说"继续象棋"然后我去搜**：用户不需要记路径，他只需要项目名的自然语言
4. **应急流程放 memory，行为准则放 CLAUDE.md**：全局指令筛选原则
5. **改 CLAUDE.md 前自查三问**：能落地吗 / 有更省的吗 / 有副作用吗

## 使用方式

用户打开终端直接打字，不需要记路径：

```
继续象棋    → 搜 中国象棋.md → 恢复
画画        → 搜 你画我猜.md → 恢复
```

## 踩过的坑

### 1. Obsidian 置顶文件名
- `_` 前缀**不能**置顶 — `_` ASCII 码 95，排在中文和字母之后
- `!` 前缀**也不能** — 同样排后面
- **结论**：不要折腾特殊字符置顶，就用 `MEMORY.md` 作为入口

### 2. 图谱"全英文"的诊断失误
- 用户说"关系图谱里全是英文文件夹名"，我第一反应是去藏 `.git` 和 `.obsidian` 文件夹
- 实际原因：图谱每个节点是一个 `.md` 文件，文件名直接显示为节点标签。19 个文件全是英文名 → 图谱全英文
- **教训**：用户描述问题时，先搞清楚系统实际显示了什么，不要凭猜测排查。`userIgnoreFilters` 只能隐藏文件，不能改变节点的显示文字

### 3. 文件名应该默认用中文
- Obsidian 和 Git 都完美支持中文文件名
- 英文文件名对中文用户的图谱和文件列表都是障碍
- **规则**：memory 仓库里所有 `.md` 文件用中文命名
