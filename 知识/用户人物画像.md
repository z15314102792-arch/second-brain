## 二、性格与行为模式

### 2.1 核心驱动力：即时反馈，而非金钱

**用户自己说的**：
> "我没有目标，也没有强烈的想赚钱的欲望。"

**AI 分析**：
用户的行动引擎不是"对钱的渴望"，而是"对反馈的渴望"。用户能坚持的事情（打王者荣耀、用 Claude Code 做游戏）都有一个共同特点：**每一步都有可视化结果**。用户放弃的事情（读书、学历史）共同特点是：**反馈周期太长**。

这不是"三分钟热度"的性格缺陷，而是一种**反馈模式偏好**。理解这一点是理解用户的关键。

### 2.2 外部约束有效，自我约束无效

用户自述能接受"明确且在预期内的 deadline"。这意味着：
- ✅ 外部给定的、清晰的任务 → 能完成
- ❌ 自己给自己定的目标 → 难以持续
- 💡 启示：副业需要外部结构化压力（平台任务、客户 deadline、发布排期），不能靠"自律"

### 2.3 独处偏好，"好为人师"

- **社交倾向**：偏好独处，因为"独处时不需要考虑别人的想法，想做什么就做什么"
- **隐藏开关**：当自己帮到别人时（"好为人师"），会产生正向情绪
- 💡 启示：可以创造"单向输出"场景（做内容、做教程），既能独处又能获得"帮到别人"的快感，不需要双向社交消耗

### 2.4 "美化自己"的自我认知偏差

用户自己承认：
> "人总是会美化自己"

这意味着用户回答问题时可能无意中给出比实际情况更积极的描述。AI 应优先采信**行为数据**（做了什么、没做什么），而非**自我陈述**（"我可以学"、"我觉得能做"）。

### 2.5 行动模式：兴奋期高产出 → 退潮后弃坑

典型案例：动物大战游戏"明明还有改进空间，但兴趣过去了，现在都懒得改了"。

这不是缺点——这是**设计副业系统时必须考虑的核心变量**。任何需要长期持续投入的副业，必须在系统中嵌入"新鲜感切换机制"。

## 六、AI 分析结论

### 6.1 用户是什么样的人

一个 23-25 岁的深圳年轻人，在小型代运营公司做视频剪辑，月薪 7-8K。技术上不会编程，但通过 Claude Code 能产出完整可运行的游戏/工具项目——这个能力在中国属于前 1%。性格偏好独处，行动依赖即时反馈，外部约束有效、自我约束无效。对赚钱没有强烈欲望，但对"看到自己做的东西跑起来、被人看到"有强烈快感。

### 6.2 用户的真正需求（可能自己没意识到）

用户说要找副业，但实际上：
- 不是真的"想要更多钱"（因为承认没有强烈的赚钱欲望）
- 而是一种"对现状隐隐不安但不知道往哪走"的焦虑
- 真正需要的是：**一个能持续给正反馈、顺便带来收入、还能提升抗风险能力的方向**

### 6.3 设计副业方案的核心约束

1. **必须有即时反馈**：每一步都要看到结果，不能"投入一个月什么都看不到"
2. **不能依赖自律**：需要外部压力或系统自动推动
3. **必须能独处完成**：不需要社交、应酬、客户扯皮
4. **不能需要"先学再用"**：必须是"做中学"，边做边有产出
5. **要有信息差**：做大多数人不知道/不会做的事，避免纯体力竞争
6. **收入预期务实**：渐进式，不追求第一个月就 4000+
7. **能提升能力**：即使收入不达预期，学到的东西本身有价值

### 6.4 用户的核心竞争优势

> **"会用自然语言驱动 Claude Code 产出完整项目"** + **"在短视频行业内部"**

这两个能力的交集处，全中国可能不到 1000 个人。

## 七、沟通注意事项

- 用户偏好直接、简洁的回答，不喜欢长篇大论的道理
- 给建议时要给出**具体可操作的第一步**，不要只给方向
- 不要用"你应该"的句式，用户对自我约束无效
- 用户可能会美化自己的能力或意愿，AI 应基于行为数据做判断
- 用户不需要被激励/打鸡血，需要的是清晰的路径和反馈节点
- 新概念、新技术术语首次出现时必须解释
