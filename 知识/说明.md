# 知识（这里放什么）

> 导航：[回到总索引 [[MEMORY]]]

放**以后都用得上的结论、道理、规则、教训**。不是流水账，是「提炼出来的东西」。

## 装什么

- 踩过的坑、总结的教训（比如 GitHub 国内访问怎么避墙）
- 长期有效的规则、结论（比如「调研先行」「卡点要止损」）
- 你自己的画像、偏好记录（人物画像 / 语言风格 / 每日关注主题 互链成簇）

## 怎么判断

问自己：**「这个结论，以后还会反复用吗？」**

- 会反复用、长期有效 → 放这里
- 只是某一天发生的一件事 → 放 [[日志/说明]]，不是这里

## 和别的目录的区别

- **知识 vs 技能**：知识是「结论」（为什么、是什么）；技能是「步骤」（怎么做）→ [[技能/说明]]
- **知识 vs 日记**：知识长期有效；日记是某一天的事
