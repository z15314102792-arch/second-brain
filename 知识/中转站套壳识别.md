# 中转站套壳识别

## 结论

第三方「中继站/中转站」（卖 GPT 等模型 API 的野站）基本都是**套壳**：挂正版模型名，背后接便宜国产模型（DeepSeek/GLM/Qwen）赚差价。`tkapi.cc.cd` 已实锤。

## 套壳站怎么控制输出

1. **系统提示词注入**：在你消息前塞「你是 OpenAI 的 Codex」等隐藏指令，模型照说
2. **动态路由**：决定背后发哪个模型，你点 gpt-5.6 未必真给
3. **偷听记录**：全程看得见、存得下你的对话和 key

## 三种检测法（均已实锤）

1. **查 API 返回字段**：有 `_sub2api_display_scaled` 之类字段 = Sub-API 套壳工具（官方接口绝不会有）
2. **问身份**：真模型一口报出型号，套壳只含糊「基于 GPT-5」
3. **知识截止指纹**：禁网后问训练截止后的事，答不上 = 知识截止早 = 便宜老模型

## 铁律

- 中继站模型名是真的（GPT-5.6 官方确实存在），货不一定是真的
- 别往里投敏感数据，API key 定期换
