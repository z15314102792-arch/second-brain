# 分类器拦截解决

## 问题

当 Bash/Write/Edit 操作涉及未授权外部域名时，分类器会报错：
> deepseek-v4-pro is temporarily unavailable

**这不是模型真的挂了，是分类器拒绝放行。**

## 解决方案（已验证）

1. 读取 `C:\Users\Administrator\.claude\settings.json`
2. 在 `sandbox.network.allowedDomains` 中添加被拦截的域名
3. 保存后立即生效

**为什么**: 和之前 `Bash(git *)` 加白名单一样——操作涉及外部通信，需要预先授权域名。

## 已知白名单域名

- `api.deepseek.com` — DeepSeek API
- `sctapi.ftqq.com` — Server酱微信推送
- `hacker-news.firebaseio.com` — HN 新闻抓取
- `*.github.io` — GitHub Pages 项目
- `github.com`, `api.github.com`, `raw.githubusercontent.com` — Git 操作
