# 2026-08-19 进度

## ⚙️ Claude Code 自动压缩阈值配置（75%）

用户需求：上下文达到 75% 时自动压缩，不靠手动 `/compact`。

### 查证结论（调研先行，claude-code-guide 子 Agent 查官方文档 + GitHub issues）

- Claude Code **原生支持自动压缩**，默认开启，实际触发点约 83%~95%（内部预留输出缓冲）
- 官方环境变量 `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`（1-100，默认 95）是触发百分比开关
- **只能调低不能调高**（内部 `Math.min(用户值, 默认值)` 钳制）——75% 属调低，有效
- 坑：`autoCompactEnabled` 不是 settings.json 合法键（写了被忽略）；`contextWindowUsageLimit` 不存在；hook 没有"用量到 X% 触发"的事件（PreCompact 不能阻止压缩）
- 不选 hook 方案：原生环境变量一行搞定，最省事

### 改动

- `C:\Users\Administrator\.claude\settings.json` 的 `env` 块新增一行 `"CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "75"`

### 验证结果

- ① JSON 语法有效，读取到的值 `"75"` ✅
- ② 进程环境已加载（`printenv CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` 输出 `75`），**改 settings.json 即时生效，无需重启** ✅
- ③ 端到端触发验证**未做**（快速验证方案被用户拒绝，改为自然观察）

## 🛠️ 保存进度命令修复（根因：漏 git 同步）

用户发现：保存进度时没做 git push，且进度文件放错位置。

### 根因（查 `C:\Users\Administrator\.claude\commands\保存进度.md`）

1. **写入路径错**：命令写的是 `E:\第二大脑\session-{日期}-progress.md`（根目录），正确应为 `日记\2026-08-{日期}-进度.md`

### 修复

- 重写 `C:\Users\Administrator\.claude\commands\保存进度.md`：
  - 写入路径改为 `日记\2026-08-{今天日期}-进度.md`
  - 格式要求改为模仿 `日记/2026-08-15-进度.md`（emoji 主题标题 + `## 改动的文件` + `## 待办`）
  - **新增第 4 步 git 同步**：pull → commit → push，且 `git add` 只加本次涉及文件（禁 `git add -A`），push 失败必须如实报告
