## 1. AI动态

### ★★★ Claude Code 默认启用 Auto 模式
[Claude Code 官方博客](https://claude.com/blog/auto-mode-default-in-claude-code) | [HN讨论](https://news.ycombinator.com/item?id=49239021)

- **发生了什么**: Anthropic 将 Claude Code 的默认模式改为 Auto 模式，AI 现在可以自主决定何时执行命令、何时请求用户确认，而非之前较保守的“每步都问”模式。
- **为什么重要**: 这意味着 AI 编码助手从“辅助工具”向“自主代理”迈了一大步。对开发者来说，AI 能更流畅地处理多步骤任务（比如重构、跑测试、修 bug 循环），效率提升明显。
- **跟我有啥关系**: 如果你用 Claude Code 写小游戏逻辑（比如棋盘 AI、碰撞检测），Auto 模式能自动跑完“改代码→跑测试→修报错”的循环，你只需要在关键节点把关。建议试一下，如果觉得太激进可以调回原来的确认模式。

### ★★ Docker 推出 AI Agent 专用沙箱
[Docker Sandboxes 产品页](https://www.docker.com/products/docker-sandboxes/) | [HN讨论](https://news.ycombinator.com/item?id=49239751)

- **发生了什么**: Docker 发布了专门为 AI Agent 设计的一次性隔离沙箱，Agent 可以在里面安全地执行代码、操作文件，用完即焚，不用担心污染宿主环境。
- **为什么重要**: AI Agent 最让人担心的是“乱跑代码搞坏环境”，Docker 从官方层面解决了这个信任问题，会加速 AI Agent 在开发流程中的普及。
- **跟我有啥关系**: 暂时关系不大。你做的是 GitHub Pages 静态部署，不涉及容器化。但如果以后想用 AI 自动测试游戏逻辑，这个沙箱会是个安全的选择。

### ★★ Meta 发布 30B 开源编码模型 Muse Glimmer
[Meta AI 研究博客](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model) | [HN讨论](https://news.ycombinator.com/item?id=49241679)

- **发生了什么**: Meta 开源了一款 30B 参数的本地编码模型，主打 agentic（能自主调用工具、多轮交互），权重完全开放。
- **为什么重要**: 30B 是“消费级显卡能跑”和“性能够用”的甜点尺寸，Meta 下场意味着开源本地模型在编码场景的竞争会进一步白热化，对闭源 API 价格形成压力。
- **跟我有啥关系**: 暂时关系不大。你的项目规模不大，用 Claude/GPT 的 API 足够；如果以后想省钱且有一张 24GB 显存的卡，可以关注这个模型做本地代码补全。
