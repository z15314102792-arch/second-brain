## 1. AI动态

### ★★★ DeepSeek Harness 开发者预览版发布，AI Agent 开发门槛再降
[DeepSeek Harness developer preview](https://deepseek.com/harness/en/)
- **发生了什么**：DeepSeek 发布了 Harness 开发者预览版，这是一个面向 AI Agent 开发的工具框架，旨在简化智能体的构建、测试和部署流程。
- **为什么重要**：继 DeepSeek V4 Pro 之后，DeepSeek 正在从"模型提供商"向"全栈 AI 开发平台"延伸。Harness 类工具正在成为大厂标配（OpenAI 有 Codex、Anthropic 有 Claude Code），竞争从模型层蔓延到工具链层。
- **跟我有啥关系**：如果你未来想给游戏加 AI 功能（比如智能 NPC、自动关卡生成），这类工具能大幅降低开发复杂度。作为独立开发者，值得关注其正式版发布后的能力和定价。

### ★★★ Gemini 3.7 Flash 发布，低成本高性能再进一步
[Introducing Gemini 3.7 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/)
- **发生了什么**：Google 发布了 Gemini 3.7 Flash，这是 Flash 系列的最新迭代，主打低延迟、低成本，面向高频调用场景。
- **为什么重要**：Flash 系列一直是 Google 在"性价比"赛道的拳头产品。这次升级意味着开发者可以用更低的成本获得更强的能力，尤其是对延迟敏感的应用场景。
- **跟我有啥关系**：如果你考虑给游戏接入 AI 功能（比如 AI 对手决策、动态剧情生成），Gemini Flash 系列的低成本特性值得关注，尤其是对调用量大的场景。

### ★★ 一份 Prompt，11 个模型，结果天差地别
[Choosing an AI model: one prompt, 11 models, different results](https://www.netlify.com/blog/one-prompt-11-models-very-different-results/)
- **发生了什么**：Netlify 发布了一篇实测文章，用同一个 Prompt 测试了 11 个主流 AI 模型，结果显示不同模型的输出质量、风格和准确性差异极大。
- **为什么重要**：模型选择没有"万能答案"，不同任务需要匹配不同的模型。盲目跟风"最强模型"可能既浪费钱又得不到好效果。
- **跟我有啥关系**：如果你未来给游戏接入 AI，别只盯着一个模型。多模型对比测试（就像 Netlify 做的）应该成为你的标准流程，找到最适合你场景的那一个。

### ★★ Codex 登陆 ChatGPT Linux 桌面版，开发者体验再升级
[Codex in ChatGPT desktop app for Linux is now in preview](https://community.openai.com/t/codex-in-chatgpt-desktop-app-for-linux-is-now-in-preview/1390027)
- **发生了什么**：OpenAI 的 Codex 编程助手正式进入 ChatGPT Linux 桌面应用预览版，Linux 用户终于可以在桌面端直接使用 Codex 进行编码辅助。
- **为什么重要**：Linux 是开发者占比最高的操作系统之一，Codex 登陆 Linux 意味着 OpenAI 正在认真对待开发者生态，补齐平台覆盖的短板。
- **跟我有啥关系**：如果你用 Linux 做开发，现在可以在桌面端直接使用 Codex 辅助编码，不用再依赖网页版或命令行，开发体验会更顺畅。

### ★★ AI 在家庭场景的应用探索：从一堆废料开始
[AI At Home Part 1: A Box Of Scraps](https://jdagostino.github.io/ai-pt1-box-o-scraps/index.html)
- **发生了什么**：一篇个人博客记录了作者用一堆废旧硬件搭建家庭 AI 实验环境的过程，展示了低成本 DIY AI 的可能性。
- **为什么重要**：AI 不只能跑在云端，本地化、低成本化的探索正在民间兴起。这对数据隐私和离线场景有特殊意义。
- **跟我有啥关系**：作为独立开发者，这种"用现有资源低成本试错"的思路很值得借鉴。你的小游戏项目也可以先用免费或低成本工具验证想法，再决定是否加大投入。

## 4. 今日小结

**新闻评价**：

今天最值得关注的是 **DeepSeek Harness 开发者预览版**。它标志着 DeepSeek 正式从"卖模型"切入到"卖工具链"，这与 OpenAI Codex、Anthropic Claude Code 形成正面竞争。对于独立开发者来说，工具链的竞争是好事——意味着未来会有更多免费或低成本的选择来构建 AI Agent 工作流。另一个值得留意的是 Netlify 的多模型对比测试，它提醒我们：**不要迷信单一模型**，实际测试才是选型的唯一标准。

**项目评价**：

昨天批量给多个项目添加验收系统（.claude/verify.js + contracts），这是一个非常正确的方向。有了这套系统，后续每次改动都能自动化验证功能完整性，避免"改一处坏一处"的回归问题。尤其是中国象棋升级到 5 维度检查，覆盖更全面。

一个值得注意的点：**五子棋和螺丝消除只更新了验收结果文件，但没看到对应的代码改动**。这可能是之前已经改过代码、昨天只是补跑验收；但也可能是验收系统本身有问题导致结果不一致。建议确认一下这两个项目的验收结果是否真实反映了代码状态，避免"验收通过但实际有 bug"的情况。

另外，**VideoClaw 新项目启动**值得祝贺。AI 短剧解说视频是个有潜力的方向，建议尽早确定 MVP 范围，快速上线验证市场反馈，不要一上来就追求功能完整。
