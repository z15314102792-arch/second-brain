## 1. AI动态

### ★★★ 给其他 Claude Code 会话发消息
**标题:** [Message your other Claude Code sessions](https://code.claude.com/docs/en/cross-session-messaging) | [HN讨论](https://news.ycombinator.com/item?id=49222824)

- **发生了什么:** Claude Code 新增了跨会话消息传递功能，允许一个终端会话直接向另一个正在运行的 Claude Code 会话发送消息。这意味着你可以在不同项目或不同终端窗口之间，让 AI 代理互相协作或转交上下文。
- **为什么重要:** 这是 AI 编程代理从"单次任务执行者"向"多代理协作系统"演进的关键一步。对开发者来说，多会话协同意味着更复杂的自动化工作流成为可能。
- **跟我有啥关系:** 如果你用 Claude Code 写过脚本或管理过项目，这个功能可以直接帮你省去手动复制上下文的时间。不过对于纯 GitHub Pages 静态站部署，暂时关系不大。

### ★★ ChatGPT 开始阻止直接模仿作者文风
**标题:** [ChatGPT stops cloning famous writers' voices but may capture a similar feeling](https://arstechnica.com/ai/2026/07/chatgpt-stops-cloning-famous-writers-voices-but-may-capture-a-similar-feeling/) | [HN讨论](https://news.ycombinator.com/item?id=49227718)

- **发生了什么:** OpenAI 更新了 ChatGPT 的输出策略，不再允许用户直接要求"以某位作家的风格写作"，但模型仍能捕捉类似的情感基调或叙事氛围。
- **为什么重要:** 这是 AI 内容生成在版权和伦理合规上的又一次收紧，说明平台正在主动规避法律风险，而非等待监管强制。
- **跟我有啥关系:** 如果你用 AI 写游戏文案或剧情，建议避免在 prompt 中直接点名真人作者，改用风格描述词（如"冷峻的黑色电影旁白"）来达到类似效果。

### ★ 用 Claude 追踪丢失手机
**标题:** [Lost my phone at the office. Claude suggested tracking Bluetooth signal strength](https://twitter.com/un1c0rnioz/status/2084686552299634805) | [HN讨论](https://news.ycombinator.com/item?id=49215786)

- **跟我有啥关系:** 暂时关系不大。不过这个思路可以借鉴到游戏里——比如在解谜游戏中设计"信号强弱找物品"的机制。
