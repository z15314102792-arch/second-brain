### ★★★ [Needle2：仅14MB的端侧Agent大模型，专为手机/穿戴设备/智能家居/机器人设计](https://cactuscompute.com/needle)
- **发生了什么**：Cactus Compute 推出 Needle2，一个体积仅 14MB 的 Agent 大模型，可在手机、穿戴设备、智能家居和机器人等资源受限设备上本地运行。
- **为什么重要**：14MB 的模型体积意味着端侧 AI Agent 的门槛被大幅拉低，离线、隐私、低功耗的智能设备 Agent 成为可能，是端侧 AI 小型化的重要里程碑。

- **跟我有啥关系**：昨天日报也提到了这个模型，今天它再次出现在新闻中，说明热度持续。如果你有 24GB 显存的本地机器，可以尝试用它跑本地代码补全或 Agent 任务，减少 API 依赖。
