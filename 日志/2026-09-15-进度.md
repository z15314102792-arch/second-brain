## Flow 操作认知纠偏

### 角色
姜宁、韩东均改为从原角色视觉设定中裁取两张干净参考：
- 人像 / 脸部近景：负责脸与身份；

### 场景
实测确认 Flow 左侧“场景”会进入 SceneBuilder / 时间线场景编辑器，并不是“固定环境资产”的场景母版槽。

因此派出所会客室继续按上传参考图 / ingredient 使用。用户最终决定继续使用已经锁定的第一次生成 `派出所会客室｜场景母版 v1.png`，不继续为了二维画风反复重做母版。

### Agent
右侧“未命名的会话”属于智能体 / Agent 层，曾出现“智能体运行失败”。本项目需要明确控制模型、参考图、数量和成本，因此当前生成优先使用标准生成框，而不是依赖 Agent 自动路由。

## 图片模型实测

### Nano Banana 2
多轮结果出现：
- 姜宁脸被标准化成通用动漫脸；
- 服装从母版深黑 / 深灰方向漂成浅灰、毛衣或廉价职场感；
- 体态变僵、显老、臃肿；
- 风格多次偏真人、2.5D / 3D。

结论：当前不作为《失踪者名单》最终图片主模型。

### Nano Banana Pro
同一角色参考下，能够更接近：
- 二维国创动漫写实向；
- 姜宁原服装、体型、年轻感；
- 韩东的疲惫、旧衣和低存在感。

当前图片主模型暂定 **Nano Banana Pro**。这一结论是项目试跑结果，不升级为第二大脑全局模型规则。

## 提示词方法的关键纠偏

用户明确指出：给模型的提示词必须基于“模型能听懂什么”构建，而不是把人类导演语言直接塞进去。

本轮固化：

> **剧情意图 → 可观察动作 / 几何关系 → 模型提示词。**

不再把以下内容作为核心执行语句：
- “保持《失踪者名单》的风格”；
- “错认姜昭”；
- “情绪防线松动”；
- “低存在感”；
- “不要男主化”。

改为具体视觉变量：
- 摄影机在谁的肩后、朝哪个方向；
- 人物在画面左 / 右 / 前景 / 后景的占比；
- 韩东坐哪把椅子；
- 臀部在椅面、椅背在肩背后、大腿进入桌下、双脚落地、桌沿在腹部前；
- 眼神固定方向、上眼睑轻微抬高、眉心放松、嘴唇轻微分开；
- 身体、头部、肩膀哪些必须保持不动。

多参考图也必须明确职责，避免每张图都同时影响身份、构图、风格和空间。
