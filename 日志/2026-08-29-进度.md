# 2026-08-29 进度

## Gemini / Antigravity 使用路线回滚与重判

背景：

- 用户希望像使用 Claude Code 一样在 VS Code/终端里使用 Gemini。
- 之前尝试将 `gemini` 命令包装为 Antigravity CLI，但在 VS Code PowerShell 中持续出现路径识别问题。
- 用户要求停止该思路，重新分析可能性和问题点。

结论：

- 旧 `Gemini CLI 0.57.0` 使用个人 Google 登录时已被官方停用，终端报错提示迁移到 Antigravity 套件。
- 本机官方 Antigravity CLI 已安装并可直接运行：
  - `C:\Users\Administrator\AppData\Local\agy\bin\agy.exe`
  - 版本：`1.1.22`
- VS Code 官方扩展已安装：
  - `C:\Users\Administrator\.vscode\extensions\google.google-antigravity-1.1.0`
- 不再推荐把 `gemini` 命令手工包装成 `agy`，因为该方案在 Windows + VS Code + PowerShell 中会增加路径、缓存和权限混乱。

已执行：

- 恢复 `gemini` 为旧 Gemini CLI 原始包装器：
  - `C:\Users\Administrator\AppData\Roaming\npm\gemini`
  - `C:\Users\Administrator\AppData\Roaming\npm\gemini.cmd`
  - `C:\Users\Administrator\AppData\Roaming\npm\gemini.ps1`

  - `C:\Users\Administrator\AppData\Roaming\npm\gemini-cli.ps1`

  - `C:\Users\Administrator\AppData\Roaming\npm\ag.ps1`
  - `C:\Users\Administrator\AppData\Roaming\npm\ag.cmd`

  - `HTTP_PROXY=`
