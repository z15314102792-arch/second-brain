## Google Drive 临时上传目录修复

### 问题原因

- `E:\第二大脑\.tmp.driveupload\` 是 Google Drive 桌面版的临时上传目录。
- 该目录中的数字文件主要是 Google Drive 为上传 `.git\objects`、`.git\objects\pack` 等 Git 内部文件而创建的临时硬链接。
- 把 `.tmp.driveupload\` 加入 git 后，会形成循环：git 提交产生新对象 → Google Drive 上传 Git 对象 → 生成临时上传文件 → git 又看到新增/删除 → 再提交又产生新对象。

### 已完成修复

- 保留本地 `E:\第二大脑\.tmp.driveupload\`，不删除用户本地文件。
- 从 git 跟踪中移除 `.tmp.driveupload\`。
- 更新 `E:\第二大脑\.gitignore`，加入 `.tmp.driveupload/` 和 `.tmp.driveupload`。
- 以后 Google Drive 继续生成或删除该临时目录时，git 不再显示这批临时文件。
