# 2026-09-24 进度

## Codex 桌面版新建任务无法切换模型

- 目标：解释新建“工作”任务时模型和推理强度固定在 GPT-6 Astra、高，切换时报“无法更新模型设置”的原因。
- 已核实：本机桌面日志在切换请求后记录 `config/batchWrite` 失败，具体为无法将设置持久化到 `C:\Users\Administrator\.codex\config.toml`。当前默认配置确为 Astra、高；文件可读取且 TOML 可解析。
- 根因：2026-09-17 启动的旧 Desktop Commander Node.js 子进程占用 `config.toml`；Windows 文件替换测试返回拒绝访问。此进程由独立的 Desktop Commander remote 服务派生，未证实属于某个具体 Codex 会话。
- 修复：备份配置后只结束占用文件的旧子进程；应用配置接口实际改值和恢复均成功。用户在新建“工作”任务页确认模型、推理强度都可切换，桌面日志显示写入成功；最终默认值为用户选定的 `gpt-6-sol`、`xhigh`。
- 本次知识文件：[[资料/Codex桌面版模型切换故障]]。
- 后续关注：Desktop Commander remote 服务仍在运行，新子进程目前没有再次占用配置文件；若复发，先确认占用进程。
