# 螺丝消除 · 解压小游戏

**版本**: v1.2 | **创建**: 2026-08-11

## 简介

基于抖音爆款 **Screw Jam（螺丝消除）** 玩法复刻的 HTML5 解压小游戏。
拧下彩色螺丝，放入同色收纳盒，清空所有面板即可过关。

## 技术

- 单文件 HTML，Canvas 2D 渲染
- Web Audio API 全合成音效（7种游戏音效 + BGM）
- 关卡自动生成（渐进难度，无限关卡）
- GitHub Pages 部署

## 核心玩法

1. 点击螺丝拧下
2. 匹配当前收纳盒颜色 → 直接进入
3. 不匹配 → 放入底部临时区（满了就输）
4. 面板螺丝全部拧下 → 面板掉落 → 暴露下层
5. 所有螺丝清空 → 过关
