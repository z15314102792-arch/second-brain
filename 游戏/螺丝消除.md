# 螺丝消除 · 解压小游戏

**版本**: v2.3 | **创建**: 2026-08-11

## 简介

基于抖音爆款 **Screw Jam（螺丝消除）** 玩法复刻的 HTML5 解压小游戏。
拧下彩色螺丝，放入同色收纳盒，清空所有面板即可过关。

## 技术

- 单文件 HTML，Canvas 2D 渲染
- Web Audio API 全合成音效（8种游戏音效 + 温暖氛围 BGM）
- 关卡自动生成（渐进难度，无限关卡）+ 贪婪求解器可解性验证
- GitHub Pages 部署

## 核心玩法

1. 点击可操作的螺丝（亮色）拧下 — 被遮挡的螺丝呈半透明🚫状态，一眼分辨
2. 颜色匹配当前收纳盒 → 螺丝**向上飞入盒子**
3. 颜色不匹配 → 螺丝**落入底部临时区**
4. 面板只剩1颗螺丝 → **物理倾斜**：木板绕剩余螺丝旋转悬挂
5. 面板螺丝全部拧下 → 面板支点旋转下落
6. 所有螺丝清空 → 自动收纳暂存螺丝（逐个飞入盒子）→ 过关
