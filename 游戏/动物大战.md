## 项目概述

抖音上热门的「电子榨菜」类动物自动对战游戏。两只动物在竞技场内随机移动、撞墙弹跳、自动战斗。每种动物有符合自身特性的攻击方式和技能。

## 技术栈

- 单文件 HTML5 Canvas + 原生 JavaScript
- GitHub Pages 静态托管
- 竖屏手机适配（自适应屏幕宽度）

## 当前功能 (v0.7)

- **图标放大3倍**：所有动物/小鸡/蛋尺寸×3，手机上清晰可见，适合录屏
- **撞墙反弹修复**：`_clampToArena` 触碰边界自动换随机方向，不再贴墙停滞
- **熊冬眠延迟**：开局2-4秒后才可能冬眠，不会起手原地不动
- **被动范围适配**：大象践踏/狮子威慑/狼独行/蛇毒溅射范围与攻击距离同步缩放
- **其他适配**：击退系数3→8、跟随偏移/投射物碰撞距离均按尺寸比例
- 9种动物 + 通用机制(5%暴击/远程Miss/闪避)
- 碰撞后摇(350ms) + 眩晕免疫(2500ms)
- 鸡3阶段蛋+4阶段生命周期 → 滚雪球
