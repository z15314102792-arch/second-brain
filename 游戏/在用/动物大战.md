## 项目概述

抖音上热门的「电子榨菜」类动物自动对战游戏。两只动物在竞技场内随机移动、撞墙弹跳、自动战斗。每种动物有符合自身特性的攻击方式和技能。

## 技术栈

- 单文件 HTML5 Canvas + 原生 JavaScript
- GitHub Pages 静态托管
- 竖屏手机适配（自适应屏幕宽度）

## 当前功能 (v0.4)

- 9种动物 + 6种新被动特性
- 创造者模式：手动选动物或随机匹配，2x速度推荐录屏
- **近战攻击=身体接触触发**（修复v0.3攻击不到bug）
- **图标全面放大~40%**（大象48px、熊42px等），视觉更冲击
- 母鸡🐔：远程撒米🍚 + 下蛋🥚（蛋4阶段：🥚→🐣→🐤→🐥，30秒孵化，不限数量但脆弱HP12可被打碎）
- **新被动特性**：
  - 🐻棕熊·狂暴（HP<30%伤害+50%）| 🐺狼·缠绕（撕咬减速30%）
  - 🦅鹰·破盾（暴击无视护盾）| 🐍蛇·缠绕（攻击减速35%）
  - 🐘大象·巨兽（免疫眩晕）| 🐢乌龟·反伤（壳状态反伤25%）
- DOT类技能（流血/中毒）命中触发
- 寻敌AI：45%朝最近敌人，30%朝中心
- 蛋有血条，敌方碰到即攻击蛋
- 竖屏布局，手机直接可用
- 快捷键：空格开始/R重置/F随机/1-3调速
