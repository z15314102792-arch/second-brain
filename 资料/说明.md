# 资料（这里放什么）

放**某个具体工具怎么装、怎么配、参考信息**。查工具的时候翻这里。

## 装什么

- 某个软件的安装/配置记录（比如「手机 Claude 怎么装」「CCE 多模型怎么配」）
- 工具的使用参考、型号信息

## 怎么判断

问自己：**「这是关于某个具体工具的信息吗？」**

- 是关于具体工具的安装、配置、参考 → 放这里
- 是通用方法（不限于某个工具）→ 放 `技能/`，不是这里

## 和别的目录的区别

- **资料 vs 技能**：资料 = 某个工具怎么配；技能 = 通用操作步骤
- **资料 vs 知识**：资料 = 查工具信息；知识 = 结论和教训
