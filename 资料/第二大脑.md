# 第二大脑（记忆系统）

**版本**: v4.12 | **状态**: AI 驱动维护中

## 当前架构

```
Codex / Claude Code 会话
  → 读取 MEMORY.md + CLAUDE.md
  → 按分类写入项目、知识、技能、资料、日志、仓库、待办、灵感
  → Obsidian 负责浏览和图谱
  → Git 负责备份到 GitHub
```

## 核心入口

| 文件 | 用途 |
|------|------|
| `E:\第二大脑\MEMORY.md` | 总索引，每个正式文件一句话 |
| `E:\第二大脑\CLAUDE.md` | AI 操作手册，规定分类、保存、git 同步规则 |
| `E:\第二大脑\日志\YYYY-MM-DD-进度.md` | 每天发生了什么 |
| `E:\第二大脑\日志\AI日报记录\YYYY-MM-DD-AI日报.md` | 自动生成的 AI 日报 |
| `E:\第二大脑\项目\记忆系统.md` | 第二大脑建设过程、版本演进和踩坑 |
| `E:\第二大脑\待办\2026-08-28-第二大脑整理候选.md` | 当前整理候选清单 |

## 当前分类

| 目录 | 用途 |
|------|------|
| `项目/` | 正在做或做过的具体事 |
| `知识/` | 长期有效的结论、规则、教训 |
| `技能/` | 照着步骤就能做的操作指南 |
| `资料/` | 某个工具、系统、配置的参考资料 |
| `日志/` | 每日进度流水账 |
| `日志/AI日报记录/` | AI 早报/日报等信息聚合 |
| `仓库/` | 废弃方案、备份、历史基线 |
| `待办/` | 已定下来但还没做的清单 |
| `灵感/` | 还没想清楚要不要做的点子 |
| `_垃圾站/` | 不要但暂不永久删除的内容 |
| `系统/` | API 密钥等敏感信息，本地专属，不进 Git |

## 自动化与同步

- 保存进度时更新当天 `日志/YYYY-MM-DD-进度.md` 和相关项目/资料/知识文件。
- Git 同步顺序固定为 `git pull origin master` → 白名单 `git add` → `git commit` → `git push origin master`。
- `系统/`、`.obsidian/plugins/`、`.smart-env/`、自动生成 skill 目录不加入 Git。
- Obsidian 用来浏览笔记和图谱；AI 负责检索、归类、维护。
