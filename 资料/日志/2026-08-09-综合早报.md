# 2026-08-09 综合早报

---

## 1. AI动态

### ★★★ 给其他 Claude Code 会话发消息
Claude Code 新增了跨会话消息传递功能，允许一个终端会话直接向另一个正在运行的 Claude Code 会话发送消息。这意味着可以在不同项目或不同终端窗口之间让 AI 代理互相协作或转交上下文。

### ★★ ChatGPT 开始阻止直接模仿作者文风
OpenAI 更新了 ChatGPT 的输出策略，不再允许用户直接要求"以某位作家的风格写作"。如果要用 AI 生成游戏文案，建议避免在 prompt 中直接点名真人作者，改用风格描述词。

### ★ 用 Claude 追踪丢失手机
一位用户在办公室丢了手机，Claude 建议利用蓝牙信号强度追踪，最终成功找回。展示了 AI 在非编程领域的实用价值。
