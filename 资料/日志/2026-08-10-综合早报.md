## 1. AI动态

### ★★★ Claude Code 默认启用 Auto 模式
Anthropic 将 Claude Code 的默认模式改为 Auto 模式，AI 现在可以自主决定何时执行命令、何时请求用户确认。这意味着 AI 编码助手从"辅助工具"向"自主代理"迈了一大步。

### ★★ Docker 推出 AI Agent 专用沙箱
Docker 发布了专门为 AI Agent 设计的一次性隔离沙箱，Agent 可以在里面安全地执行代码、操作文件，用完即焚。

### ★★ Meta 发布 30B 开源编码模型 Muse Glimmer
Meta 开源了一款 30B 参数的本地编码模型，主打 agentic（能自主调用工具、多轮交互），权重完全开放。

### ★ OpenChamber: 开源 Agentic 开发环境
一个开源的"Agent 优先"IDE 项目，把 AI Agent 作为开发环境的一等公民来设计。

### ★ 用 LLM 学习复杂主题的经验帖
一位开发者分享了他用 LLM 学习复杂技术主题的具体方法。
