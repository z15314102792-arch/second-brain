## 本次优化记录

### 2026-08-06

**新增规则（3 条）：**
- 编码前自查第四问：我判定的问题，放在用户的实际使用场景下还是问题吗？
- 改 CLAUDE.md 前自查三问：能落地吗 / 有更省的吗 / 有副作用吗
- 有更好的就说：回答完后发现更优方案提一句，不确定的不说

**重写规则（2 条）：**
- 任务执行：旧"简单任务直接做" → 新"不需要读文件和做判断的纯信息收集自己直接做，例外：目录分散或命令超过 5 条时分派"
- 调研先行、自测五维度、版本标示：加了微小改动豁免

**关键讨论：**
- 规则太绝对对 LLM 的影响：绝对词（每次/必须）会导致微小操作也触发重型流程，需要加"非微小改动"豁免
- 中文自然语言 vs 混合格式（结构化+正反例）：当前规则 < 20 条，纯中文足够。超过 25 条或出现规则互相矛盾时考虑切换
- Anthropic prompt engineering 最佳实践：结构化声明 + 正反例 + 自然语言说明三者组合执行准确度最高
- 分派 Agent 的判断标准：按复杂度不按话题，纯信息收集不分派，需要读文件和做判断才分派
