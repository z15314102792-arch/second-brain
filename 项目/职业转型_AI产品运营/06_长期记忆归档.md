## 2. 离职与转型基线

当前结论：暂不裸辞。

90天不是机械辞职倒计时，而是职业验证周期。

90天内应保留现金流，同时推进：
- JD分析
- 能力补齐
- 作品集
- 简历
- 投递
- 面试
- 市场反馈复盘
是否离职不由情绪判断，而由真实反馈决定。

优先离职触发条件：
- 拿到合适 AI 应用类 offer
- 当前工作明显阻碍转型
- 通勤、工作量或管理状态恶化
- 已完成职业验证，且只差全职投入

若未来考虑裸辞，至少准备6个月必要生活费，更稳妥为9个月。

## 5. 核心能力缺口

### 5.1 产品思维

以下为学习方向，不是本阶段全部先修要求；按01/05中的具体任务取用。

需要掌握：需求 → 用户 → 场景 → 痛点 → 解决方案 → 指标 → 验证。
不能只问“这个 AI 工具有什么功能”，要转成：
- 用户为什么有这个问题？
- AI 放在哪一步最有价值？
- 怎么证明方案有效？

### 5.2 数据能力

目标不是成为数据分析师，而是能用数据判断 AI 产品或 AI 流程是否有效。

需要补：
- Excel / Google Sheets 基础
- 百分比、环比、同比
- 转化率、漏斗、留存、ROI
- 基础数据图表
- A/B Test 基础
- AI 产品常用运营指标

### 5.3 AI 工作流独立设计

目标从“跟教程搭出来”变成“给一个业务问题，能独立拆流程”。

优先复用已接触工具；不预设必须从Coze升级到n8n。

不同时学习 Dify、Make、Zapier、LangChain、CrewAI 等框架，除非当前项目真正需要。
### 5.4 AI 基础原理

不走算法路线，但必须能解释：
- LLM
- Token
- Context Window
- Prompt
- Structured Output
- Function Calling / Tool Calling
- Agent
- Workflow
- RAG
- Embedding
- API
- 模型幻觉
- Temperature
- 多模态
- MCP

要求不是背定义，而是能解释“为什么这里应该用工作流而不是 Agent”。

### 5.5 作品集

不能再用“我会 ChatGPT、Gemini、Coze”作为能力证明。

必须转成：我解决了什么问题、原来怎么做、为什么用 AI、怎么设计、遇到什么失败、最后效果如何、节省多少时间、成功率多少。
