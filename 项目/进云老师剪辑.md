## 工作流程

### 工具链（实际可用）
- **转录**：本地 Whisper medium（离线，免费，中文支持）
- **文本分析**：DeepSeek API（`sk-...`，已配置在环境变量中）
- **视觉分析**：智谱 GLM（`ZHIPU_API_KEY` 已配置）
- **剪辑**：ffmpeg（trim + transpose + eq + concat）
- **不可用**：ElevenLabs Scribe（缺 API key）、Cassette（缺 API key）
