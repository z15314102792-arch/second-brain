## 项目概述

抖音上热门的「电子榨菜」类动物自动对战游戏。两只动物在竞技场内随机移动、撞墙弹跳、自动战斗。每种动物有符合自身特性的攻击方式和技能。

## 技术栈

- 单文件 HTML5 Canvas + 原生 JavaScript
- GitHub Pages 静态托管
- 竖屏手机适配（自适应屏幕宽度）

## 当前功能 (v0.2)

- 9种动物：母鸡🐔、棕熊🐻、狼🐺、公牛🐂、鹰🦅、蛇🐍、狮子🦁、大象🐘、乌龟🐢
- 创造者模式：手动选动物或随机匹配，2x速度推荐录屏
- 母鸡完整机制：远程撒米🍚 + 下蛋🥚孵化（蛋→雏鸡→青年鸡→成年帮手）
- DOT类技能（流血/中毒）改为命中触发，不是远程自动挂
- 竖屏布局，手机浏览器直接打开可用
- 快捷键：空格开始/R重置/F随机/1-3调速

## 待改进
