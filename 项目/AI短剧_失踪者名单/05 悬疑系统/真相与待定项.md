# 《失踪者名单》真相与待定项

用途：把“已经确定的事实”“角色认知”“推测”“尚未设计的问题”分开，避免悬疑靠作者故意藏信息。

## 当前上帝视角已确定

- 姐姐过去与池恹存在重要关联。  
- 姐姐早期为了带女主离开原有不安全生活，在时间压力下进入灰色工作；具体家庭事件仍待设计。  
- 姐姐早期的一次选择真实伤害了 X，后来试图补偿 X，并因此逐渐卷入更大事件。  
- X 不是单纯工具人或绝对无辜受害者，他有自己的目的与过去选择；但不扩展为与主线并列的完整副线。  
- 姐姐与池恹的关系不是从“姐姐直接救他”开始，而是经利益冲突、互不出卖、合作及后续互相救助逐步形成。  
- “姐姐让池恹离开”是当前最后可靠事件。  
- 池恹离开之后发生了什么，目前没有确定答案。姐姐不确认死亡。  
- 现在时开场由“失踪多年的 X 重新出现”触发，使姐姐多年没有进展的旧案重新产生新信息。  
- X 的回归机制暂定为：当年相关幸存/逃离人员近期重新有人失踪或出事，X 判断隐姓埋名已无法保护自己，因此主动恢复真实身份并向警方求助。X 主动提到姐姐旧失踪案并要求联系家属，警方通过旧案联系人找到女主。  
- 女主职业暂定心理咨询师；她能够观察情绪、语言和关系模式，但没有可靠读心或微表情测谎能力。  
- 姐姐早期寻找 X 的方式确定为灰色外围“核址/确认位置”：上游提供已有信息，她负责确认，不负责抓人；她进入更深灰色场所靠工作信任逐层获得许可，不靠潜入。

## 当前不再作为事实的设定

- 不存在因为暂定标题而被强制设定的一张“万能秘密名单”。  
- 之前考虑过的内部转移名单仅视为废弃/待重构机制，不用于当前事实链。  
- 《失踪者名单》仍是工作标题。当前更优方向是女主在调查中逐渐发现多个失踪者之间存在交叉关系，并自行建立关联名单/图谱；是否最终保留这一形式仍可调整。

## 角色可能相信、但不是事实

- 多数过去相关人物可能根据当时情况认为姐姐已经死亡。  
- 女主在故事开始时可能已经接受“姐姐大概率不在”的社会结论，但她对姐姐失踪的真实心理状态仍待定。  
- X 可以通过一句真实但不完整的话，使女主先形成“池恹最后把姐姐留下”的判断；这不是完整因果。  
- 池恹是否相信姐姐已经死亡，目前待定。

## 过去线最关键待定问题

- 姐姐与女主原生家庭具体发生了什么，使她必须在短时间内筹资源离开。  
- X 当年到底做了什么，姐姐收到的信息哪里真实、哪里被省略。  
- X 后来要求姐姐完成什么具体事情。  
- 该事件如何把姐姐自然带到池恹所在的灰色世界切片。  
- 池恹当时自己的目标是什么。  
- 后期重大逃离/冲突事件具体是什么，为什么需要姐姐留下、池恹带人离开。  
- 池恹离开后姐姐真实发生了什么。  
- 姐姐是否仍活着；如果仍活着，为什么多年没有回到女主身边。

## 现在线最关键待定问题

- 近期具体是哪位旧相关人员重新失踪/出事、发生了什么，X 掌握到什么程度，为什么这足以迫使他公开身份。  
- X 多年隐姓埋名期间如何生活、使用什么身份，以及他当下仍承担哪些旧风险。  
- X 为什么愿意透露池恹，他此刻想从女主或这件事里得到什么。  
- 女主作为心理咨询师的具体执业方向、个人生活与心理状态，以及她如何从 X 的碎片一步步找到池恹。  
- 池恹为什么愿意见女主，又为什么不能/不愿一次性说出全部信息。  
- 现在时的主要对手或压力想阻止什么被重新翻出来。  
- 哪些人掌握彼此冲突但各自真实的过去版本。

## 真相阶梯原则

每次揭露都应真正回答一个已有问题，同时改变人物关系或制造一个更深的问题。  
不能只通过“某人就是不说”来拖延。角色不说必须有自己的利益、恐惧、承诺或信息边界。  
不同角色只能依据自己实际获得的信息作出判断；世界本身就允许“没有任何一个人掌握完整真相”。  
优先采用“之前知道的并非全是假，而是不完整”的重构式悬疑，而不是频繁用完全推翻前文的强行反转。  
在真实时间线没有设计清楚前，不提前确定最终反转。

## 后续需要拆成的文件

真实时间线：事情实际发生顺序。  
故事呈现时间线：观众和女主获知信息的顺序。  
线索与伏笔表：每个线索何时出现、表面含义、真实含义、何时回收。  
人物知情表：每个角色在每个阶段到底知道什么。
