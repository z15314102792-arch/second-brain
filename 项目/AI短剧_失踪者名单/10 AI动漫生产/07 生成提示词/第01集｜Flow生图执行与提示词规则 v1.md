# 第01集｜Flow 生图执行与提示词规则 v1

## 1. 当前工具结论

- 当前图片主模型暂定：**Nano Banana Pro**。
- Nano Banana 2 在本项目多次产生 2.5D / 3D、通用脸、偏真人材质和服装体态泛化，暂不作为最终图片主模型。
- Flow 左侧“场景”是 SceneBuilder / 时间线，不是固定环境母版资产槽；派出所等固定场景以上传参考图使用。
- 需要明确可控模型、参考图和成本时，优先标准生成框，不依赖 Agent 自动路由。

## 2. 母版优先级

1. 原始角色视觉设定 = 身份真源。
2. Flow角色 = 便于生成时调用的生产资产。
3. 镜头生成图 = 当前镜头候选，不得反向替换角色母版。

当前：
- 姜宁：Flow角色使用脸部裁图 + 正面全身裁图；原角色视觉设定 v1 最高优先。
- 韩东：Flow角色使用脸部裁图 + 正面全身裁图；原角色视觉设定 v1 最高优先，表情页只负责演技。
- 派出所：继续使用第一次生成的 `派出所会客室｜场景母版 v1.png`，墙面 AI 文字不属于正式设定。

## 3. 提示词总规则

**先由总控理解剧情，再把剧情翻译成模型能直接画出的内容。**

不要只写：
- “这是《失踪者名单》的风格”；
- “韩东错认姜昭”；
- “情绪防线松动”；
- “低存在感”；
- “不要男主化”。

这些词可以用于人类内部分析，但不能作为核心执行指令。

模型输入优先写：
- 摄像机位置、方向、景别；
- 人物在画面的位置、占比、前后层级；
- 门窗、桌椅和人物的几何关系；
- 身体是否坐 / 站，四肢与家具的关系；
- 视线、眼睑、眉心、嘴唇、头部、肩膀的可见变化；
- 哪些区域 / 元素必须完全不变。

一句话：**剧情意图 → 可观察动作 / 几何关系 → 模型提示词。**

## 4. 多参考图职责

每张输入都必须只承担明确职责：
- `@角色`：身份、脸、发型、年龄、服装；
- 已通过上一镜：人物位置、空间连续性、镜头轴线；
- 场景母版：门窗、桌椅、柜子、饮水机等固定结构；
- 风格图：只有在确实需要时负责线条、材质、光影。

失败时优先减少同时约束，不继续无限添加说明。

## 6. B02-B 下一轮输入方案

### 输入
- 参考图：B02-A 通过候选，只负责位置、桌椅和空间连续性。
- `@韩东`：只负责韩东身份。
- 暂不强制挂 `@姜宁`；左前景只定义可见女性特征，降低约束冲突。
- Nano Banana Pro，16:9，x1。

### 提示词 v2

```text
参考上一张 B02-A 画面的空间关系和人物位置。

保持韩东仍然坐在 B02-A 中同一把椅子上。
不要改变韩东的座位。
不要改变桌子、椅子和韩东之间的位置关系。

使用 @韩东 作为韩东唯一人物身份参考。

【画面构图】
16:9横画幅。
摄影机移动到姜宁身后、略偏右的位置，朝向韩东。
这是一个越肩中近景。

画面左前景只出现一名年轻女性的：
- 黑色低盘发
- 少量后脑
- 左侧肩膀
- 黑色西装外套轮廓

前景轻微虚化，占画面左侧约20%，不能遮挡韩东的脸。

【韩东的位置｜最高优先级】
韩东必须坐在长桌右侧、B02-A中的同一把黑色办公椅上。

明确表现他的坐姿：
- 臀部完整落在椅面上
- 后背靠近椅背
- 椅背在他的肩部和身体后方清楚可见
- 大腿向前伸入桌下
- 双膝弯曲约90度
- 小腿位于桌子下方
- 双脚踩在地面
- 身体不能站立
- 身体不能离开椅面
- 不能坐在桌子边缘

长桌前沿位于韩东腹部前方。
桌面必须挡住他部分下半身，以明确他坐在桌边。

【韩东身份】
严格保持 @韩东 参考中的瘦长脸型、原有眼型和眼距、鼻型、嘴型、下巴比例、凌乱黑发、轻微胡茬、眼下疲惫感、偏瘦体型、暗色旧外套和灰色内搭。
不要重新设计脸。

【韩东表情】
韩东看向左前方的女性。
- 眼神固定在她脸上
- 上眼睑轻微抬高
- 眉心稍微放松
- 嘴唇轻微分开
- 头部几乎不动
- 肩膀保持放松
- 身体仍然坐在椅子上

表情变化很小。
不要瞪大眼睛。
不要张大嘴。
不要起身。
不要前扑。
不要做夸张震惊动作。

【场景连续性】
沿用 B02-A 中已经确定的房间结构、窗户、长桌、黑色办公椅、文件柜、饮水机和墙面位置。
不要重新设计房间。

【视觉】
二维国创写实动漫风格。
清晰二维线条，柔和克制的明暗。
韩东和背景保持同一种绘制质感。
```

## 7. 进入视频门槛

B02-B 静帧必须先通过：
- 韩东脸与身份母版一致；
- 韩东确实坐在指定椅子上；
- 前景女性不会被误判为男性；
- 派出所空间没有跳变。

未通过前不消耗视频额度。通过后先做一次低成本图生视频试跑，再做一个双人 / 反打代表镜头，之后才决定是否进入整集全量生产。
