# 《失踪者名单》当前大纲

本文件只记录能支撑后续正文的主脊柱，不展开配角人生、对白、镜头或分集。  
原则：先保证“为什么发生下一件事”的因果成立，再进入场景级剧情。

## 一、过去线：当前已确定主脊柱

1. 姐姐长期承担保护/照顾女主的重要角色，并希望带女主离开原有不安全生活。  
2. 某个尚未确定的家庭危机与明确期限迫使姐姐不能靠普通方式慢慢积累资源。  
3. 姐姐通过引路人接受灰色外围工作，主要是跑腿、核址、确认人员位置、递送东西等。上游已经提供照片、旧地址、联系人和活动范围，她依靠不显眼、耐心和应变完成确认，而不是独自侦查或抓人。她知道工作不干净，但用“只要我不直接伤害别人就不算参与”来自我合理化。  
4. 姐姐为了报酬确认并上报了 X 的位置，真正的抓捕/施压由别人完成。X 因此遭遇严重后果，这是姐姐第一次无法回避的真实越界。  
6. 姐姐因办事可靠、嘴严且已经卷入，逐渐承担更内部的送款、送文件、带路等任务，因此被允许进入灰色场所；不是靠单人潜入。  
6. X 并非纯粹无辜：他确实做过危险或违法边缘选择，但姐姐最初得到的解释并不完整。  
7. 姐姐后来重新接触 X，意识到自己的选择造成了什么。X 不单纯求救或感激，而是利用姐姐的愧疚要求她替自己完成一件具体事情。  
8. 姐姐最初只是想补偿 X，不想拯救整个地下世界。她在帮助 X 的过程中一点点看到更大的灰黑利益网络，并逐渐无法把自己当成旁观者。  
9. 池恹在这条线中因自己的独立目标与姐姐发生利益冲突。他不是姐姐一开始就要救的人，也不是简单受害者。  
10. 姐姐与池恹通过互相掌握把柄、在可以出卖对方时选择不出卖、被迫合作以及后续互相救助逐步建立信任。救助是关系发展的结果，不是起点。  
11. 过去线后期会发生一次比最初“小规模补偿/逃离计划”更大的事件。姐姐最终基于现实功能和因果需要选择留下，让池恹带人离开。  
12. “姐姐让池恹离开”是当前最后可靠事件。此后发生什么、生死如何，没有上帝视角确定答案。

## 二、过去线：当前必须补的关键因果

- 家庭中究竟发生了什么，使姐姐必须在明确期限内带女主离开。  
- X 当年究竟做了什么，姐姐得到的版本与真实情况分别是什么。  
- X 要姐姐帮的“那一件事”是什么，它如何自然把姐姐推向更深层网络。  
- 池恹当时自己的独立目标是什么；为什么他与姐姐会在同一事件上发生冲突。  
- 后期重大事件的具体机制，为什么必须有人留下，以及为什么最后由池恹负责带人离开。  
- 之前曾考虑用“内部转移名单”连接上述环节，现已撤回，不再把暂定片名反推成万能道具。中段机制需重新设计。

## 三、现在时：当前锁定开场

1. 故事从女主现在时开始。姐姐的过去不会按完整时间顺序先讲给观众。  
2. 当年相关的幸存/逃离人员近期重新有人失踪或出现异常，X 意识到隐姓埋名已经不能继续保护自己，于是主动恢复真实身份并向警方求助。身份核验显示：X 本人多年前已经被登记失踪。  
3. X 主动提到姐姐旧失踪案并要求联系她的家属。警方通过旧案中保存的家属/联系人信息找到女主；女主此前不需要认识 X。  
4. X 见到女主后认出她与姐姐的关系，并给出一个指向池恹的关键但不完整事实片段。当前优先方向：让女主先形成“池恹可能在最后关头把姐姐留下”的理解。  
6. X 不负责一次性解释过去。他只提供足以推动下一步行动的信息。  
7. 女主利用正常社会中的现实调查能力追查池恹，由公开/半公开信息一步步抵达灰色世界门口。  
8. 女主第一次真正进入自己不熟悉的规则范围后，池恹的地下生存经验与危险判断开始成为不可替代的能力。男女主由此产生“她需要他的过去和能力、同时怀疑他可能伤害过姐姐”的天然冲突。

## 四、现在时：下一阶段要补到的程度

在正式写正文前，至少需要确定：  
- 近期究竟是哪位旧相关人员重新失踪/出事，X 得到了什么信息，为什么足以迫使他公开身份。  
- 女主职业暂定心理咨询师；仍需确定年龄、具体执业方向、个人生活状态，以及姐姐失踪多年后她目前对这件事处于什么心理状态。  
- X 为什么会同意见女主/说出池恹，以及他此刻自己的目的。  
- 女主从 X 给出的碎片如何实际找到池恹，不能靠偶遇。  
- 池恹现在时是什么状态，为什么会见女主，为什么不直接离开。  
- 女主与池恹第一次会面结束后，什么新问题迫使两人继续产生联系。  
- 主要对手或当前压力何时第一次在现在时主线中产生作用。

这些成立后，即可把第一阶段拆成具体场景并开始正文，不需要先补完整个世界和所有配角人生。
