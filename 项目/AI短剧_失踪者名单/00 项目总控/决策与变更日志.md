# 《失踪者名单》决策与变更日志

用途：记录重要方向变化、调整原因和版本判断。当前有效内容以《当前有效设定》为准。

## 版本 0.1｜项目初始化

故事方向暂定“失踪者名单”。原因：它能同时承载女主独立目标、人物网络、悬疑推进和危险关系。  
危险关系采用 B 型为主：女主逐步发现池恹并非自己最初认识的那个人；吸引、信任、恐惧和依赖可以同时增长。  
主题暂定 C“被抛弃”为底层，A“爱与占有”与 B“真相与记忆”为表层。此主题处于试用状态，可继续修改。

## 修正 01｜姐姐与池恹的关系起点

旧方向：姐姐一开始直接帮助池恹，并由此形成强烈情感关联。  
调整原因：关系建立过于直接，容易落入现成套路。  
当前要求：两人的关系应经过更早的事件、利益、冲突或共同处境逐步形成；后续可以出现重要帮助，但它必须是关系发展的结果，而不是起点。

## 修正 02｜姐姐的生死

旧方向：默认姐姐已经死亡。  
当前方向：姐姐生死未知。最后可靠事件暂定为“姐姐让池恹离开”，此后没有可靠画面或上帝视角结论。其他角色可以基于当时情况推定她已不在人世，但这只是角色认知。

## 修正 03｜池恹原始人设的使用方式

决定：用户提供的人设全文不直接视为正文既定事实。  
保留：视觉辨识度、极端依恋、强占有倾向、强行动能力、对女主卑微与对外危险的反差，以及“害怕被抛弃”的核心。  
待筛选：过去经历、具体伤痕来源、具体高风险行为、已经发生的感情节点等。  
原因：原始人设同时包含人物素材与已经发生的关系剧情，需要重新给故事留下发展空间。

## 决策 04｜人物设计总原则

决定：“每个人都是自己世界的主角”作为人物设计原则，但不等于所有角色拥有同等篇幅。  
重要角色必须有独立于男女主的欲望、利益、恐惧、关系和价值排序；他们帮助、阻碍或背叛别人都应来自自己的选择，而不是单纯执行剧情功能。  
限制：人物丰满不等于展开完整人生。只有会改变主线选择、关系、真相或结果的内容进入正文。若删除某段配角信息不改变这些核心变量，则优先留在人物档案或不写。  
原因：避免工具人，也避免“为了丰满而无限扩支线”。

## 决策 05｜姐姐过去线采用“具体补偿对象”方向

在“逃出去 / 摧毁体系 / 补偿具体受害者”三个方向中，确定采用第三种作为姐姐过去线的核心发动机。  
姐姐最初不是为了调查地下世界或当英雄，而是为了带妹妹离开不安全的原有生活，在时间压力下进入灰色工作。她早期的一次选择真实伤害了 X；后来试图补偿 X，由此一点点卷入更大的灰黑利益网络。  
X 定位为“剧情铰链人物”：需要有自己的欲望与立场，但不扩展成与主线并列的完整人生副线。

## 决策 06｜现实世界与能力边界

确定采用现代现实逻辑下的架空城市。没有修真、超自然、科幻能力或超现实科技。  
地下体系不写成控制全城的单一巨大组织，而是多个灰黑利益环节交叉形成的松散网络；每个人只知道自己接触的部分。  
女主来自正常社会，具备现实可解释的信息追查/资料整理/沟通能力，但不是特工、黑客或超强打手。  
池恹具备灰色世界生存经验、近身搏斗和危险判断能力，但不是超人，信息也有边界。

## 修正 07｜“名单”不反推剧情

旧方向：曾考虑存在一份关键内部转移名单，并让 X、池恹和世界揭露都围绕它运作。  
问题：暂定标题开始反过来绑架剧情，一张名单承担过多世界观、悬疑和行动功能，存在“万能道具”风险。  
当前方向：《失踪者名单》仍只是工作标题。女主可以在调查过程中自己逐渐整理出多个失踪者之间的关联，从而形成“失踪者名单/关联图”；但不强制存在一张包揽全部秘密的内部名单。作品最终标题仍可更换。

## 决策 08｜开场入口

确定故事从现在时开场，不先完整讲姐姐过去，也不优先采用“男女主高潮对峙后大段倒叙”。  
触发事件：失踪多年的 X 在现实社会中重新出现，使姐姐多年没有进展的失踪事件第一次出现新信息。X 通过警方、医院或其他正式系统完成身份核验后，被确认是多年以前登记失踪的人；他重新出现的具体原因待定。  
X 见到女主后认出她与姐姐的关系，并提供一个指向池恹的关键但不完整事实片段。女主由正常社会的追查方法逐步找到池恹并抵达灰色世界入口。  
原因：同时满足吸引力、背景提示、主线启动和悬疑保留，并避免靠偶遇或女主突然拥有不合理能力推动故事。

## 决策 09｜女主职业暂定心理咨询师

女主职业暂定为心理咨询师。采用该职业不是为了赋予“读心/测谎”能力，而是为了自然支持她的倾听、情绪与语言变化观察、回避识别、关系模式理解和创伤敏感度。  
限制：微表情、眼神等只能成为提出假设的弱线索，不能直接推出谎言或真实想法；女主必须可能误判，尤其在本人情绪卷入时。具体执业方向与工作场景仍待定。

## 决策 10｜X 的现在时回归机制暂定

X 当年长期隐姓埋名；近期当年相关的幸存/逃离人员重新有人失踪或出现异常，使他意识到“继续隐藏”已经不再安全，于是主动恢复真实身份并向警方求助。  
X 主动提到姐姐的旧失踪案并要求联系家属；警方通过旧案联系人找到女主，女主此前无需认识 X。  
暂不采用“X 在警局门口遭公开枪击/暴打”的开场版本，原因是会显著抬高犯罪网络的暴力尺度和警方介入强度，与当前松散灰黑网络的现实尺度冲突。如需要危险感，可让 X 在到警局前已经遭遇威胁或受伤。

## 决策 11｜姐姐寻找 X 与进入灰色场所的现实化

姐姐不设为练家子、侦探或专业跟踪者。她最初做的是灰色外围的跑腿/核址/确认位置等工作，上游已经提供目标的照片、旧地址、联系人和活动范围；姐姐利用低威胁外表、耐心、应变和社会观察确认 X 的位置，不负责抓人。  
姐姐随后因办事可靠、嘴严、缺钱且已经越界，逐步承担更内部的送款、送文件、带路等任务，因此被允许进入灰色场所；不采用单人潜入地下拳场的方式。


## 决策 12｜AI 动漫为主产物，新增小说支线

项目输出结构正式调整为“双轨但有主次”：AI 动漫是主要产物；小说作为同一项目中的叙事母稿、剧情验证和改编素材，同时允许独立阅读。  
目录新增 `12 小说`；原 `10 AI生产` 改名为 `10 AI动漫生产`，不重排既有编号。  
AI 动漫不要求等待整部小说完成后才开始，只要某一阶段剧情达到可改编颗粒度，即可从小说 + 讨论 + 当前有效设定中提取场景和镜头。

## 决策 13｜小说正文写作原则与第一章启动

正文不先展示女主日常，第一句话直接由电话铃声切入异常事件。女主“心理咨询师”职业只在剧情需要时以最少信息自然带出。  
小说采用快节奏、场景驱动、背景后置原则；删去不改变剧情、理解、人物选择或氛围的无关信息，不追求为了完整而完整。  
第一章初稿已启动，任务只做到：X 回归 → 女主见到 X → 姐姐“并非被动进入”的第一次认知翻转。当前未提前写池恹或尚未确定的真相。

## 决策 14｜核心人物姓名与姜宁年龄

确定：女主姓名为姜宁，年龄22岁；姐姐姓名为姜昭；原代号 X 的角色姓名为韩东。  
暂不确定：姜昭年龄、姐妹年龄差、具体失踪年限。此前为配合错认提出的“姐妹在同一年龄节点重合”只保留为候选思路，不作为事实。  
正文不因为姓名已经确定就强制立刻写出；姓名应在官方核验、他人称呼、自我介绍、错认等自然节点出现。

## 决策 15｜用户修改样本的使用方式

用户会直接基于阅读感觉修改小说措辞、顺序、称呼、动作和节奏。这些修改用于学习目标阅读体验，但不自动视为正确写作规则。  
当前偏好包括：剧情尽快启动；反感机械问答；动作描写必须对应当下心理；快节奏不等于为了减字而减字；背景后置；人物全名只在心理距离和语境合适时使用。  
执行原则：后续写作同时参考用户样本与叙事判断。若用户建议会破坏因果、人物心理、清晰度或整体节奏，应明确指出并讨论，不为迎合而照抄。详细样本见 `12 小说/小说写作偏好与审稿标准.md`。

## 维护规则

重大设定修改需记录：旧方向、调整原因、新方向、是否已同步到当前有效设定。  
小措辞优化不必记录。

## 决策 16｜对白按“认知位置 + 说话目的 + 节奏”审稿

补充小说对白判断标准：不能只比较两句话传递的字面事实是否近似，还必须判断说话人此刻掌握的信息、说话目的、权力/情绪关系和句式节奏。  
示例：“姜昭是你姐姐吗？”偏向询问未知信息；“姜昭是你姐姐，对吗？”偏向对既有资料的正式确认。在当前警方电话场景中，后者更符合“警方已经查过旧案、现在向本人确认”的认知位置。  
该示例不是固定句式模板；以后应逐场景判断，避免把用户的单次修改机械固化成规则。  
本轮只记录标准，不修改第一章正文；正文继续保持“先讨论敲定，再统一修订”的流程。

## 决策 17｜第一章重写改用“人物目的 + 状态变化密度”流程

针对第一章试写暴露出的“人机对白、问一句答一句、推进拖沓”问题，停止在旧稿上逐句润色。后续重写先保留既定事件，再从人物目的、隐藏信息、认知位置和场景状态变化重新生成。

对白方面：警察只完成工作职责，不替作者讲案情；姜宁真正关心姐姐，但多年假线索使她会压住希望；韩东是主动要求见姜宁的人，必须有自己的谈话路线，不能被动等待逐条审问。人物可以回避、反问、答潜台词或打断，但必须由自己的目的驱动。

节奏方面：快节奏不以字数短或短句多为标准，而以“有效变化密度”为核心。采用“晚进场、早离场”；重大认知变化允许停顿，无效过程压缩；小悬疑及时给阶段性答案，并用答案生成更大的问题。先检查宏观场景推进，再处理微观句式与描写。

第一章下一版至少包含四个清晰状态变化：电话让多年沉寂的旧案重新启动 → 见面确认韩东与姐姐确有深层联系 → 韩东回归说明过去危险正在重新活动 → 章节结尾推翻姜宁旧认知：姐姐不是被动进入，而是主动找过去。

本决策仅更新写作方法与审稿标准，不新增尚未确认的剧情事实，不修改姐姐生死、池恹后续秘密等未定内容。

## 决策 18｜正文进入“局部修订 + 修改样本长期学习”阶段

第一章经过多轮试写、用户人工微调和对白/信息结构校准后，当前已有一版用户主观阅读体验较好的工作稿，下一步先等待读者反馈，不继续为修改而修改。

正文修订方式调整为：默认只修改真正有问题的部分；无问题段落原样保留。若一个问题会牵连前后文，只扩大到必要范围；只有整场戏结构失效时才重写整场。此前“下一版不沿旧稿修补、重新生成整章/整场”的方法不再作为默认规则。

新建并持续维护 `12 小说/写作修改样本与语言学习.md`，保存 AI/旧稿与用户人工修改之间的对比，分析为什么某些修改更自然、哪些只是个人偏好、哪些可能造成信息模糊或其他负优化。用户修改是高价值阅读样本，但不自动等于正确写作规则。

对白和信息组织继续采用本轮校准后的原则：角色有自己的主动表达路线；一个完整交流动作不强拆成连续问答；读者始终应知道当前主要问题；基础事实及时给出阶段性答案，再由答案生成更深问题。

当前第一章工作稿中的部分具体情节仍属于正文实验。未被《当前有效设定》确认的内容不得因为已经写进工作稿就自动升格为项目事实。本决策只更新写作流程与学习机制，不新增姐姐生死、具体年龄差、失踪年限、池恹现状等未定事实。
