# 《失踪者名单》项目导航

当前阶段：第一章暂定定稿，第一集已进入 Google Flow 图片生产试跑；当前不是全量逐镜生产，而是用派出所 B02 代表镜头验证“角色一致性 + 场景连续性 + 静帧到视频”的完整链路。  
主目标：AI 动漫。小说作为同一项目内的叙事母稿与素材源，用于验证剧情、人物、节奏，并为后续 AI 动漫的分集、场景、镜头和角色表演提供依据。  
原则：所有内容均可继续补充、修改或推翻；未确认内容必须标注“待定”，重大调整写入变更日志。

## 10 AI动漫生产

本项目主产出目录。后续统一使用中文命名，避免新会话被英文术语干扰。当前目录索引如下：

- `01 整体视觉设定/`：全片画风、光线、城市质感、悬疑基调、颜色与总体审美。
- `02 角色设定/`：角色视觉设定、表情设定、视觉与表演说明。当前已含 `姜宁/`、`韩东/`。
- `03 场景设定/`：第一集实际需要的场景资产。当前先建 `姜宁工作空间/`、`派出所/`。
- `04 镜头清单/`：第一集镜头拆分、景别、动作、台词、资产需求和视频优先级。
- `05 分镜草图/`：由镜头清单继续转化为可视化分镜。
- `06 起始帧/`：后续图生视频前锁定人物、构图和场景连续性的起始画面。
- `07 生成提示词/`：人物、场景、分镜、起始帧和视频生成提示词。
- `08 生成版本/`：实际生成出来的图片/视频版本与候选结果。
- `09 审片记录/`：连续性、画风、表演、镜头可用性和返工记录。

**视觉生成强制前置链：**凡进入 `05 分镜草图/`、`06 起始帧/`、`07 生成提示词/`、`08 生成版本/` 或 `09 审片记录/` 的实际生图/视频生成工作，先实际读取 [[技能/AI短剧创作执行指南]] → [[技能/AI短剧镜头与提示词细则]] → [[技能/AI视觉生成长期规范]]，再读取当前镜头对应的角色/场景/道具母版和 Shot List。文件存在或旧会话记忆不算已调用。

命名统一：后续项目文件、目录和索引一律使用上述中文名称；旧英文目录名不再作为正式名称使用。

AI 动漫不机械照搬小说，而是综合小说正文、项目讨论与当前有效设定进行影像化改编。每做一项资产都必须能回答“后面的哪个镜头会用它”，回答不出来就先不做。

## 当前已经锁定的重要推进

- 现代现实逻辑下的架空城市，无超自然/科幻能力。  
- 灰色世界为松散利益网络，而非无所不能的单一组织。  
- 姐姐过去线采用“早期越界伤害 X → 想补偿 X → 被逐渐卷入更大网络”的方向。  
- X 是剧情铰链人物，不扩展成抢占主线的完整副线。  
- 暂定标题不反推剧情；不强设一张万能秘密名单。  
- 现在时开场由“失踪多年的 X 重新出现”触发。X 认出女主，并提供指向池恹的关键但不完整信息。  
- 女主靠正常社会的现实调查方法追到灰色世界门口；池恹负责她不具备的地下规则与危险生存能力。

## 当前下一步

当前不再继续扩角色卡或重做场景母版，也不直接整集逐镜生成。

生产试跑顺序：

1. 先把 B02-B（韩东近景错认姜昭）静帧做稳定：韩东脸必须保持身份母版、必须坐在 B02-A 同一把椅子上，姜宁只作为轻前景。
2. B02-B 静帧通过后，立即做一次低成本图生视频测试，验证微表情、脸部稳定和动作连续性；视频模型尚未最终冻结，以实际试跑结果为准。
3. 再补 1 个双人对话 / 反打代表镜头验证连续性。
4. 只有这 2～3 个代表镜头完整跑通，才停止测试，进入第一集全量逐镜生产。

当前图片主模型暂定 **Google Flow / Nano Banana Pro**。Nano Banana 2 在本项目实测中多次把角色推向 2.5D / 3D、通用脸和偏真人质感，不作为当前最终图片主模型。

提示词执行规则已调整：不得把“《失踪者名单》的风格”“错认姜昭”“情绪防线松动”等项目名或抽象导演语言直接丢给图像模型；必须先翻译为可见、可画的镜头信息，例如相机位置、人物在画面中的几何位置、坐姿关系、视线、眼睑、嘴唇、肩颈和动作幅度。多参考图必须明确每张图只负责什么。

### 当前 Flow 资产状态

- 姜宁：已在 Flow 角色中用“正面脸部裁图 + 正面全身裁图”建立角色；原始 `姜宁｜角色视觉设定 v1` 仍是最高身份母版，Flow 生成图不得反向替代。
- 韩东：已在 Flow 角色中用“脸部裁图 + 全身裁图”建立角色；原始角色视觉设定 v1 仍是最高身份母版，表情页只负责表演参考。
- 派出所：继续使用用户已锁定的第一次生成 `派出所会客室｜场景母版 v1`；不再为追求画风继续反复重做场景。墙面 AI 文字不属于正式设定。
- B02-A：建立镜头已得到一张当前可用候选，门位正确，姜宁在左侧入口，韩东坐在室内桌边；暂作为后续空间连续性参考。
- B02-B：尚未通过。主要卡点为韩东近景脸漂移、人物有时离开椅子 / 空间关系错误，以及前景姜宁可能被模型生成成男性轮廓。下一轮应使用 B02-A 作为位置连续性参考 + `@韩东` 作为身份参考，并把“坐在椅子上”写成明确几何关系。
