# 《失踪者名单》当前有效设定

状态：开发中，可持续修改。本文件只保存当前有效版本；未确认内容不得写成事实。

# 项目定位

女频恋爱 / 危险关系 / 悬疑 / 连续叙事。  
当前仍处于 Story Development（故事开发）阶段，不进入分集、剧本、分镜和 AI 出图。

# 当前故事方向

女主为了追查失踪多年的姐姐，进入一个与地下拳场及灰色利益网络有关的旧事件。  
池恹是与姐姐过去存在重要关联、并掌握关键碎片信息的人。  
核心发动机暂定：女主越接近自己最想知道的真相，越可能失去自己越来越不想失去的人。

# 当前主题

底层主题：被抛弃。  
表层主题 A：爱与占有。  
表层主题 B：真相与记忆。  
当前理解：池恹因害怕失去而倾向抓住、占有；女主可能因害怕失去而倾向不真正依赖任何人。此项仅为当前方向，需随女主人设和剧情继续验证。

# 姐姐：当前有效规则

姐姐不确认死亡。  
最后可靠事件暂定停在“姐姐让池恹离开”；池恹离开后发生了什么，目前未知。  
其他角色可根据当时现场、条件和后续证据推断姐姐已经死亡，但“死亡”不能作为上帝视角事实。  
姐姐为什么进入地下体系、进入后的真实目标、最终去向，均为待定。

# 姐姐与池恹：当前有效规则

禁止使用“姐姐一出现就直接救下池恹，因此池恹感恩”的简单关系起点。  
两人的关系必须由更早的事件、利益、冲突或共同处境逐步形成。  
后续可以出现姐姐救助池恹，但必须是前序关系和事件发展出的结果，而不是关系的默认起点。

# 池恹：当前保留核心

保留其强视觉辨识度、对女主极端依恋、强占有欲、暴力能力、对内卑微与对外危险的反差。  
保留“害怕被抛弃”“把爱误解为抓住/属于”的核心心理方向。  
原始人设中的大量苦难细节、具体暴力事件、亲密场景和已发生感情节点，不自动视为正文事实；需要剧情时再筛选、改写或废弃。

# 当前禁止写死的内容

女主职业、年龄、完整人格与人物弧。  
姐姐是否仍活着。  
姐姐进入地下体系的真实原因。  
池恹当年究竟做过什么、知道多少。  
主要对手身份与最终目的。  
结局。  
篇幅和最终集数。

# 版本原则

所有内容均允许后续补充、修改或推翻。  
修改当前有效设定时，应同步记录“为什么改”；废弃内容移入废案，不直接抹掉历史。
