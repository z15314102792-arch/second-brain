# 《失踪者名单》当前有效设定

状态：开发中，可持续修改。本文件只保存当前有效版本；未确认内容不得写成事实。

# 项目定位

悬疑 / 危险关系 / 恋爱 / 连续叙事；受众取向不再强制锁死为女频。  
项目主产物确定为 AI 动漫；小说同步存在，但定位为叙事母稿、剧情验证与 AI 动漫改编素材，不替代 AI 动漫主线。  
当前进入“故事开发 + 小说正文试写”阶段；AI 动漫的正式分集、分镜和生成在剧情达到可改编颗粒度后启动，不要求先写完整部小说。


# 小说与 AI 动漫关系

项目内新增 `12 小说`，保存小说正文；原 `10 AI生产` 明确为 `10 AI动漫生产`，作为主产出目录。  
小说写作采用快节奏、场景驱动、背景后置原则：不为展示人物而强行写无关日常；职业、过去、世界观等只在当前剧情需要时补充。  
AI 动漫后续同时参考小说正文、讨论记录和当前有效设定进行改编；若小说与最新有效设定冲突，以最新有效设定为准。  
小说正文允许反向暴露并修正大纲问题，不视为不可修改的定稿。

# 世界规则

故事发生在现代现实逻辑下的架空城市。没有修真、超自然、科幻能力或超现实科技；警方、医院、监控、法律、手机、网络与社会运行方式原则上遵守现实世界基本逻辑。  
地下世界不是统一控制城市的庞大秘密组织，而是由非法拳赛、私人赌局、债务中介、暴力催收、人员转手、假身份和运输渠道等环节交叉形成的松散灰黑利益网络。不同人物只知道自己接触的切片，不能默认任何人掌握全貌。

# 当前故事方向

女主为了追查失踪多年的姐姐，逐渐接触与地下拳场及灰色利益网络有关的旧事件。  
池恹是与姐姐过去存在重要关联、并掌握关键碎片信息的人。  
核心发动机暂定：女主越接近自己最想知道的真相，越可能失去自己越来越不想失去的人。  
故事与世界应通过人物、事件和关系逐层揭露，不采用开场集中讲解世界设定的方式。

# 人物设计总原则

重要角色都拥有独立于主角的欲望、利益、恐惧、关系和价值排序；他们不会因为主角存在就自动改变人生轨迹。主角只是故事主要追踪的人，而不是世界里唯一拥有完整意识的人。  
“每个人都是自己世界的主角”不等于每个配角都获得同等篇幅。配角需要内部逻辑与独立立场，但只有真正改变主线选择、关系、真相或结果的部分进入正文，避免支线无限扩张。

# 女主：当前能力边界

女主姓名确定为姜宁，22岁；职业方向为心理咨询师。第一集工作场景锁定为正规心理咨询机构内的独立咨询室/办公室，不是自营诊所；具体教育路径、执业阶段与资质细节仍按现实性校准。AI 动漫第一集生产身高参考约167cm。来自正常社会，不设为特工、职业打手、黑客或全能调查者。  
她的职业优势主要体现在高质量倾听、识别情绪变化、语言回避、前后矛盾、关系模式和创伤反应，并能据此形成“对方可能在回避什么”的假设；这些判断必须结合事实和后续证据验证。  
禁止把“心理咨询师”写成微表情读心/稳定测谎能力。她可以看错，尤其当自己卷入感情、家庭创伤或既有偏见时，专业判断会受到影响。  
她仍缺乏地下世界的人脉、暴力能力和规则经验；她可以通过正常社会的信息与沟通一路追到灰色世界门口，更深处则需要新的信息源和池恹的经验。

# 池恹：当前能力边界

保留其强视觉辨识度、对女主极端依恋、强占有欲、暴力能力、对内卑微与对外危险的反差。  
池恹长期在灰色暴力环境中生存，因此可以擅长近身搏斗、危险预判、逃脱、识别地下规则与部分边缘关系；但不是超人，不能一人无伤对付大量持械成年人，也不能自动知道所有地下信息。受伤、资源不足和信息盲区都必须真实存在。  
保留“害怕被抛弃”“把爱误解为抓住/属于”的核心心理方向。原始人设中的大量苦难细节、具体暴力事件、亲密场景和已发生感情节点，不自动视为正文事实；需要剧情时再筛选、改写或废弃。

# 姐姐：当前有效规则

姐姐姓名确定为姜昭。年龄关系与失踪时间已锁定：姜昭比姜宁大6岁；5年前失踪，当时姜昭23岁、姜宁17岁；故事现在时若姜昭仍活着约28岁。  
姜昭最初进入灰色体系的主方向确定为：出于带妹妹脱离原有不安全生活的现实目标，为了在明确时间压力下快速获得资源而接受灰色工作；具体家庭危机与期限仍待设计。  
她最初不是凭个人能力追踪 X，而是受灰色外围中间人/债务相关渠道雇用，从事跑腿、核实地址、确认人员位置等低层外勤。对方已经提供照片、旧地址、联系人或活动范围，她负责的是“不显眼地确认”，不负责抓人或施暴。  
她因办事可靠、嘴严、缺钱且已经做过越界行为，逐步被允许承担更内部的送款、送文件、带路等任务，由此被正常地带入灰色场所，而不是单人潜入。姐姐不设为练家子，优势偏向胆量、应变、耐心和街头式社会观察。  
她不是从“调查地下世界”或“拯救所有人”开始。她会经历从自我合理化、真实越界、意识到后果、试图补偿具体受害者 X，再逐渐卷入更大事件的过程。  
韩东（原代号 X）是姜昭第一次无法回避的真实后果，也是把她从“赚钱”推进到“补偿”的剧情铰链人物；韩东不扩展成与主线并列的完整副线。  
姐姐不确认死亡。最后可靠事件暂定停在“姐姐让池恹离开”；池恹离开后发生了什么，目前未知。其他角色可以推断姐姐已经死亡，但“死亡”不能作为上帝视角事实。

姐妹视觉关系正式锁定：姜宁与姜昭必须具有明显家族相似性，但不是双胞胎或复制脸。共享相近的脸部基本骨架、眼型/眼距和鼻口整体比例，其中眼部相似度最强；同时眉形、眼睑/眼尾、鼻梁鼻尖、唇形嘴角、下颌与面颊软组织等必须保留稳定细微差别。姜宁美感偏清冷、利落、年轻；姜昭偏成熟、明艳、松弛，不设绝对谁更美。不能只靠发型或饰品区分，姿态、服装语言与动作节奏也必须不同。韩东对姜宁的错认是年龄接近、家族脸部特征和情绪刺激共同造成的短暂错认，认真看后应能快速意识到不是姜昭。

# 韩东（X）：当前有效规则

韩东，28岁。当前定位为重要男性角色 / 暂定男二 / 关键剧情铰链人物；他与姜昭过去的选择存在直接因果，是现在时重新启动旧案的重要触发者，但不抢占姜宁—池恹主线。  
他曾长期处于失踪状态并长期隐姓埋名。第一章外在状态暂定为落魄、邋遢、疲惫、低存在感；内里较为精明，会观察、判断和筛选信息，但“精明”只作为底色和伏笔，不表现成高智商炫技或操盘者。  
韩东与姜昭的关系暂定为亦敌亦友：有过敌对，也有过合作，存在旧账、利用、防备与有限信任；不是单纯受害者—加害者关系，也不默认浪漫关系。涉及姜昭时，韩东的情绪控制更容易出现短暂失衡。  
韩东不设为刑警、前刑警、特工、雇佣兵、职业打手或黑道男主。其职业、失踪期间具体生活方式仍待定；AI 动漫第一集生产身高参考约178cm，用于稳定同框比例。第一集服装锁定为现有角色视觉设定 v1 的旧感深色外套 + 普通内搭 + 耐穿长裤，低饱和且有使用痕迹；斜挎包等随身物不锁定。除人工确认的生产标准外，视觉生成图中未被正文或人物档案确认的职业、随身道具等不得自动视为有效设定。  

# 姐姐与池恹：当前有效规则

禁止使用“姐姐一出现就直接救下池恹，因此池恹感恩”的简单关系起点。  
两人的关系由利益冲突、互相掌握把柄、在可以出卖对方时选择不出卖、被迫合作等过程逐步形成。后续可以出现互相救助，但必须是关系发展的结果，而不是关系起点。

# 暂定标题与“名单”规则

《失踪者名单》仍是暂定工作标题，不能因为标题强行设置一张万能秘密名单。  
当前更优方向：女主在调查姐姐的过程中逐渐发现多个失踪者之间存在交叉关系，并由自己整理出“失踪者关联/名单”。这可以成为悬疑结构和标题来源，但不是一件包揽全部秘密的万能道具；最终片名仍可修改。

# 开场：当前锁定方向

故事从现在时开始，不以姐姐完整过去线作为第一场，也不采用“先放男女主高潮对峙再大段倒叙”的常规方式。  
开场触发事件：失踪多年的韩东（X）主动恢复真实身份并向警方求助，使姐姐多年无进展的失踪事件第一次出现新信息。当前暂定原因是：当年逃离/幸存的相关人员近期重新有人失踪或出现异常，X 意识到长期隐姓埋名已经不能继续保护自己，公开身份反而可能成为新的安全手段。  
韩东在警方完成身份核验后主动提到姜昭的旧失踪案，并要求联系她的家属。警方通过姐姐旧案中已有的家属/联系人信息联系到女主；女主此前不需要认识 X。  
韩东见到姜宁后认出她与姜昭的关系，并提供一个指向池恹的关键但不完整信息。当前优先方向是类似“最后把她留下的人，是池恹”这样的事实片段：它可以真实，但不提供完整上下文。  
警局门口遭公开枪击/暴打的高强度方案暂不采用，以免把灰黑网络规模抬高到与当前世界规则冲突的程度；如后续需要视觉危险，可以改为 X 在此前已经遭遇威胁或受伤。  
女主由正常社会的信息追查逐步找到池恹并抵达灰色世界入口；不是靠偶遇、超能力或单人硬闯地下世界开启主线。

# 当前主题

底层主题：被抛弃。  
表层主题 A：爱与占有。  
表层主题 B：真相与记忆。  
当前理解：池恹因害怕失去而倾向抓住、占有；女主可能因害怕失去而倾向不真正依赖任何人。姐姐也可能因保护妹妹而替她决定、隐瞒或推远她，与池恹形成主题镜像。上述人物弧仍需随正文因果继续验证。

# 姜宁人格 v1｜当前有效规则（2026-09-14）

姜宁的人格方向正式锁定为：
- 清醒、敏锐、直接，具有较强行动倾向；
- 有同理心，但有明确边界；
- 情绪不弱，只是习惯先处理事情、再处理自己；
- 不轻易依赖别人，不喜欢把安全感建立在“别人一定会留下”上；
- 对“没有答案”耐受度较低，对真相有近乎固执的需求；
- 对真实情绪有耐心，对无效绕弯和故意拖延没有无限耐心；
- 她能理解一个人的理由，但不会因为理解原因就自动原谅结果；
- 她的成熟主要体现在工作与解决问题上，不代表在人际、爱情、家庭创伤上完全成熟。

AI 动漫表演原则：
- 不把姜宁画成长期冰山脸；
- 基础表演逻辑为“有反应 → 控制 → 行动/提问”；
- 惊讶、期待、失望、恼火、恐惧、被击中、真正开心等都应有清晰幅度；
- “克制”不等于所有表情趋同。

继续待定：
- 内向或外向；
- “高冷 / 温柔 / 毒舌”等标签化气质；
- 完整爱情模式；
- 最终人物弧。

## 姜宁工作空间
- 场景性质：正规心理咨询机构内的独立咨询室 / 办公室，不是姜宁自营诊所。
- 当前场景母版：`10 AI动漫生产/03 场景设定/姜宁工作空间/姜宁工作空间｜场景母版 v1（暂定）.png`。
- 空间尺度暂定约 28–35㎡，相较早期小空间版本更宽松、不压抑。
- 视觉基调：明亮、现代、专业、舒适、有秩序；米白、浅灰、浅木、暖灰棕、少量低饱和绿，自然光偏暖但克制。
- 咨询座椅 / 沙发的颜色、材质、款式必须在不同机位保持一致。
- 门、窗、咨询座椅、小圆桌、工作桌、书架、绿植等位置关系以母版为连续性锚点。
- A02 门边接电话角度必须从 A01 母版派生，不重新设计另一间办公室。
- 母版中的城市窗景属于视觉背景；具体楼层、城市建筑不自动升级为剧情事实。

## 派出所会客室
- 场景性质正式锁定为基层派出所的**会客室 / 接待谈话室**，不是审讯室、阴暗密室、重案组会议室或高级刑侦空间。
- 当前正式母版：`10 AI动漫生产/03 场景设定/派出所/派出所会客室｜场景母版 v1.png`，采用本轮第一次生成的参考板；后续修正版不作为母版。
- 视觉基调：冷白灰、浅灰、浅木 / 灰木、深灰，少量低饱和蓝灰。
- 光线：自然光 + 普通冷白办公顶灯。正常、清楚、略冷、有制度距离感，只保留轻度压迫；不靠阴暗、恐怖光、青绿犯罪片滤镜制造悬疑。
- B02 / B03 / B04 必须共享同一空间：门、窗、桌椅、文件柜、饮水机、地面、色调和光线方向固定，只改变机位与人物站位。
- 母版中的墙面口号、门牌及 AI 生成文字不作为固定设定；需要文字时后期统一处理。
- 韩东右手伤不再单独维护 C01 场景资产；03-02 特写在正式镜头阶段使用韩东角色母版 + 已确认伤势 + 派出所母版生成。
