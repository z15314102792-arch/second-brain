# 数字人口播流水线

> 状态：**暂停**（等用户定画面端方案）

## 目标

本地自建数字人口播流水线：克隆用户的脸 + 声音 → 喂口播文案 → 出「用户本人」口播视频。用途：做 IP 口播视频，不必每次真人出镜。

## 环境（2026-08-13 检测）

| 项目 | 值 |
|------|-----|
| 显卡 | GTX 1650 / 4GB 显存 |
| CPU / 内存 | i5-10400F / 32GB |
| Python | 3.12（需装 Miniconda 建 3.10） |
| conda / WSL2 | 都未装 |
| FFmpeg | 已装 9.0 |
| 磁盘 | C 盘只剩 8.7GB → 装 D 盘（剩 250GB） |

## 关键约束（硬）

**显卡 4GB 是硬约束**，决定哪些工具能跑：

| 工具 | 角色 | 显存需求 | 4GB |
|------|------|---------|-----|
| GPT-SoVITS | 克隆声音 | 4GB 可推理 | ✅ |
| EchoMimic V2 | 克隆脸出视频 | 16GB 起步 | ❌ |
| MuseTalk | 实时唇形 | 8GB 起，实时要 3080Ti | ❌ |
| Wav2Lip | 轻量唇形 | 4GB | ✅ 但效果生硬 |
| SadTalker | 自然口播 | 6-8GB | ❌ |
| LivePortrait | 表情迁移 | 6-8GB | ❌ |

## 画面端三条路（待用户选）

1. 本地 Wav2Lip：免费、数据不出本机，但只有嘴动、表情僵硬
2. 云端数字人（即梦/腾讯智影等）：效果好，按量收费、数据出本机
3. 升级显卡：二手 12G 卡约 800-1200 元，能跑 SadTalker

## 恢复时下一步

1. 先装声音端 GPT-SoVITS（确定能跑，最值得）
2. 装 Miniconda + 建 py3.10 环境，装 D 盘
3. 画面端按用户选的路走
4. 用户需提供：正脸讲话视频/照片（脸素材）+ 干净人声录音（声音素材 ≥1 分钟）
