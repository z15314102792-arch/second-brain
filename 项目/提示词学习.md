# 提示词工程学习

> 零基础学习如何跟 AI 高效对话

## 学习路径（8 周）

```
第1-2周：打基础 → 看免费课程 + 读官方文档
第3-4周：学核心技巧 → 9 个技巧逐个练
第5-6周：做 2-3 个实战项目
第7-8周：跨平台对比 → 探索进阶方向
```

## 核心技巧清单

1. 零样本提示（Zero-shot）— 直接说清楚要什么
2. 少样本提示（Few-shot）— 给 2-3 个例子
3. 思维链（Chain of Thought）— 让 AI 一步步思考
4. 角色扮演（Persona）— 给 AI 分配身份
5. 系统提示词（System Prompt）— 设定持久行为规则
6. 结构化输出 — 要求返回 JSON/表格等固定格式
7. 分隔符与上下文锚定 — 把指令和数据分开
8. 提示链（Prompt Chaining）— 大任务拆成流水线
9. 解码参数 — 理解 temperature、top_p 等参数

## 万能模板

```
角色 → 背景 → 任务 → 约束条件 → 输出格式 → 示例 → 兜底策略
```

中文版 CO-STAR 框架：
- **C**ontext（背景）
- **O**bjective（目标）
- **S**tyle（风格）
- **T**one（语气）
- **A**udience（受众）
- **R**esponse（格式）
