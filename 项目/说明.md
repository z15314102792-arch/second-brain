# 项目（这里放什么）

放**你正在做、或已经做完的具体事**。每一个「事」一个文件。

## 装什么

- 做的小游戏 → 放 `项目/游戏/` 子目录（比如中国象棋、螺丝消除）
- 剪辑、简历、调研等具体任务 → 直接放这里

## 怎么判断

拿到一个东西，问自己：**「这个我要动手去做吗？」**

- 要动手做（或正在做、刚做完）→ 放这里
- 只是列了个计划、还没开始 → 放 `待办/`，不是这里

## 和别的目录的区别

- **项目 vs 待办**：开始动手了 → 项目；只是计划没动 → 待办
- **项目 vs 仓库**：还在推进或刚做完 → 项目；做完不玩了、废弃了 → 仓库
