# AIGC 游戏美术素材方案

> 为象棋、五子棋、你画我猜、螺丝消除、动物大战五个项目补齐美术素材。

## 核心工具对比

| 工具 | 平台 | 费用 | 难度 | 强项 | 弱项 |
|------|------|------|------|------|------|
| **即梦** | Web/App | 每日60-100积分免费 | ⭐ 极低 | 文生图快、社区指令可复制、中文理解好 | 风格雷同、"伪像素风" |
| **LiblibAI** | Web | 首充送200积分 | ⭐⭐⭐ | 模型多、可训LoRA、原创性强 | 学习曲线陡、非大佬难出精品 |
| **Midjourney** | Discord | $10/月起 | ⭐⭐ | 质量天花板、风格控制精准 | 需翻墙、英文提示词、付费 |
| **Stable Diffusion** | 本地 | 免费 | ⭐⭐⭐⭐ | 完全可控、插件生态丰富 | 需好显卡(8G+显存)、技术门槛高 |
| **DALL-E 3** | Web | ChatGPT Plus $20/月 | ⭐ | 理解力最强、指令跟随好 | 需翻墙、风格控制粗 |

## 各游戏推荐方案

### 1. 中国象棋（v3.11）

**需求：** 棋子图标、棋盘主题皮肤、红方/黑方棋子差异化视觉

**推荐方案：即梦（免费额度够用）**

提示词模板：
```
中国象棋棋子，圆形，木质纹理，{棋子名}字，红色/黑色，
中国传统风格，简洁清晰，白底，高分辨率，游戏素材
```

示例：
- `中国象棋"帥"字棋子图标，红底金字，圆形，木质纹理，简洁，游戏UI素材`
- `中国象棋"將"字棋子图标，黑底银字，圆形，木质纹理，简洁，游戏UI素材`

**预期产出：** 14种棋子 × 2色 = 28个图标，约消耗 28-56 积分（半天免费额度）

### 2. 五子棋（v1.3）

**需求：** 黑白棋子、棋盘背景、胜负动画特效

**推荐方案：即梦**

提示词模板：
```
五子棋棋子，简约风格，{黑/白}色圆形，扁平设计，
微弱阴影，干净背景，游戏素材，512x512
```

**预期产出：** 黑白棋子各1个 + 棋盘纹理1个 = 约10积分

### 3. 你画我猜（v8.14）

**需求：** 画板工具图标（画笔、橡皮、颜色盘、撤销、清空）、房间UI背景、猜词提示卡

**推荐方案：即梦（UI类素材）**

提示词模板：
```
游戏UI图标，{功能描述}，扁平风格，线条简洁，
明亮色彩，透明背景，app图标，256x256
```

**预期产出：** 约15-20个UI图标 + 3个背景 = 约50积分

### 4. 螺丝消除（v3.2）

**需求：** 螺丝钉多色图案、木板纹理、消除粒子特效帧、音乐盒图标

**推荐方案：即梦（日常素材）+ LiblibAI（如需高品质螺丝特写）**

提示词模板：
```
卡通螺丝钉，{颜色}色，俯视图，游戏道具，
可爱风格，简洁设计，透明背景，512x512
```

**预期产出：** 8-10色螺丝 + 木板背景 + 特效帧 ≈ 80-120积分

### 5. 动物大战（v4.0）⭐ 最需要美术

**需求：** 12种动物卡片插图、6张地图背景、卡片选择UI、引导页插画

**推荐方案：Midjourney（质量最优）或 即梦（国内免费替代）**

12种动物列表：鼠🐭、牛🐮、虎🐯、兔🐰、龙🐲、蛇🐍、马🐴、羊🐑、猴🐵、鸡🐔、狗🐶、猪🐷

即梦提示词模板：
```
{动物名}，战斗姿态，卡通风格，扁平设计，
明亮色彩，白色背景，游戏卡片插画，可爱但凶猛，
轮廓清晰，适合做卡牌游戏素材，1024x1024
```

MJ 提示词模板：
```
A {animal} in battle stance, card game illustration style,
flat vector art, vibrant colors, clean outlines,
white background, game asset, --ar 1:1 --style cute
```

**预期产出：** 12张动物卡 + 6张地图 + UI ≈ 三周免费额度可完成

## 操作步骤（小白版）

### 第一步：打开即梦
1. 浏览器打开 `https://jimeng.jianying.com/`（剪映旗下）
2. 用抖音/头条账号登录
3. 首页点「AI 图片生成」

### 第二步：输入提示词
- 把上面的模板粘贴进去
- 点击生成，等10-30秒
- 不满意就改提示词重新生成

### 第三步：下载使用
- 右键保存生成的图片
- 放到游戏项目的 assets 目录
- 在代码中引用即可

## 注意事项

1. **版权问题**：即梦生成的图片可用于个人项目，商业用途需确认最新用户协议
2. **风格统一**：同一游戏的素材要在同一对话中生成，保持风格一致
3. **格式转换**：下载后如需去背景，可用 remove.bg（免费）
4. **尺寸适配**：手机屏幕建议 512×512，如需高清用 1024×1024
5. **预览后再批量**：先生成1-2张看效果，满意再批量出图
