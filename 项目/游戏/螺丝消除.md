## 关键技术决策

- **单文件架构**：所有 HTML/CSS/JS/WebAudio 在一个文件中，方便部署和微信打开
- **贪心求解器**：30关×3轮保证可解，贪心卡住时评估"释放潜力"选最优
- **音乐盒 BGM**：WebAudio API 实时合成，零外部资源依赖
- **螺丝层位系统**：面板+螺丝在同一 for 循环渲染，上层面板自然遮盖下层 ghost 螺丝
- **形状精确碰撞**：圆形/三角/六角/矩形面板，shapeContains 精确判断螺丝遮挡
