# 记忆检索——动手前先查记忆库

## 触发条件

当即将执行以下操作时自动触发：
- 网络下载（curl、wget、浏览器打开链接）
- GitHub 操作（HTTPS 下载、gh CLI、Release 页面）
- 推荐下载渠道（应用商店、APK 站点）
- 涉及第三方服务（云存储、同步工具、API）
- 涉及用户手机/其他设备的操作

## 强制规则

**在执行或推荐任何涉及网络/下载的操作前，必须先用 Grep 检索记忆库。**

检索关键词示例：
- `GitHub` `国内` `访问` `墙`
- `下载` `APK` `国内` `可用`
- `已安装` `工具`

记忆库里有的信息不能凭记忆假设，必须实际检索确认。

## 特别提醒

`[[知识/GitHub国内访问]]` 明确记录了：
- GitHub HTTPS 下载一定被墙
- 只有 SSH over `ssh.github.com:443` 是通的
- `gh CLI` 走 HTTPS API，同样被墙
- GitHub 镜像站（ghproxy.com、fastgit）也不稳定

**任何涉及从 GitHub 下载文件的操作，必须先意识到 HTTPS 下载极大概率失败，优先找替代渠道。**
