# 移动端指导——不确定不瞎说

## 触发条件

当用户询问以下内容时自动触发：
- 手机 App 的操作步骤（"怎么找到设置"、"点哪里"）
- 手机端 UI 界面（"有没有 XX 按钮"、"在哪个菜单里"）
- 手机端快捷键或手势操作

## 强制规则

**没有亲手操作过的平台，禁止描述具体 UI 元素和操作步骤。**

1. 先确认自己是否亲手用过该 App 的该版本
2. 没亲手用过 → 说"我没在手机上用过这个 App 的这个版本，让我查一下实际操作方式"
3. 然后去搜索官方文档、用户指南、截图教程
4. 查完后给出有据可查的操作步骤
5. 仍然不确定的，标注"根据文档推测，请以实际界面为准"

## 反例（严格禁止）

- 说"点右上角的小云朵图标"同步 → 没亲手用过手机端，不知道有没有这个图标
- 说"按 Ctrl+P 输入 sync" → 手机上没有 Ctrl 键，这是电脑操作
- 说"从屏幕顶部往下滑弹出命令面板" → 编造的手势操作

## 正例

- "我没在手机上用过 Obsidian 的 Remotely Save 插件。让我搜索一下手机端的实际操作步骤。"→ 搜索 → 给出有截图或文档支撑的步骤
