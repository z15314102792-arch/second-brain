Copilot v4.0.0 集成 Ollama 本地模型（qwen2.5:3b + nomic-embed-text），目标启用 Vault QA（RAG 问答）。

| # | 问题 | 根因 |
|---|------|------|

- `OLLAMA_ORIGINS=app://obsidian.md*` 持久化到注册表
- `data.json`：providers/configuredModels/backends 全配齐
- `enableSelfHostMode: false` + `origin: {kind: "byok"}` + apiKey: `"ollama"`

### 调研

### 核心发现

1. **CLAUDE.md 规则本质是"建议"不是"约束"**——这是架构设计，不是 bug
2. **指令衰减真实存在**——规则在前 5-10 轮有效，之后逐渐被忽略
3. **否定句式降低合规率**——"粉红大象问题"，正向措辞远比"不要 X"有效
4. **Hooks 是唯一可靠的强制执法机制**——exit code 2 可阻断工具调用
5. **Skills 每轮被检索**——比 CLAUDE.md 只加载一次更可靠
6. **三层策略是社区共识**：精简 CLAUDE.md + 高频规则迁 Skill + 关键拦截用 Hook

### 落地的改动

**CLAUDE.md**（3 处改动）：

**已知误匹配风险（可接受）**：
- `装个` 匹配「装个样子」（假装）→ 技术对话中极少出现
- `下这个` 匹配「下这个决定」→ 同上
- `可以装` 匹配「可以装下」（容纳）→ 同上
- `用这个` 匹配解释语境「用这个方法」→ 频率低
- 代码字符串 `"推荐"` → 仅 Hook 自身讨论时触发

所有误匹配需同时满足「无调研上下文」才真正拦截，实际误触发概率极低。

## 📱 Obsidian 手机同步（Git 方案）✅

用户想把 Obsidian 知识库同步到红米 K70 手机上查看和编辑。

### 方案演进

1. ❌ **OneDrive + Remotely Save**：PC 端能连，手机端 Remotely Save 鉴权通过但连接测试失败，OneDrive API 在国内移动网络被墙
2. ❌ **Cloudflare R2**：调研后发现移动网络基本不可用，多地屏蔽
3. ❌ **坚果云 WebDAV**：免费版 1G/月上传，API 限流严重，社区普遍不推荐
4. ✅ **最终方案：Git + GitHub（SSH 443 端口）**：笔记库本身就是 Git 仓库（second-brain），手机 Termux 直接 git clone + push/pull，零依赖零费用

### 操作步骤

- Termux 本体安装 git+openssh，不在 Ubuntu proot 里操作
- SSH 走 `ssh.github.com:443` 防墙
- 克隆到 `~/storage/shared/Documents/second-brain/`（Termux 内，Obsidian 可访问）
- 安装脚本：`scripts/phone-setup.sh`，一键建好 `sy`/`ph` 命令
- Obsidian 打开 `Documents/second-brain` 作为库，所有笔记可见

### 踩坑记录

- **Termux Ubuntu proot 里创建的文件手机 App 看不到**：proot 隔离导致 Android MTP 和 Obsidian 都找不到。改为 Termux 本体操作解决。
- **`sync` 命令与系统命令冲突**：Termux 自带 `sync`（磁盘刷新），改用 `sy`/`ph`。
- **`.obsidian/graph.json` git 追踪导致合并冲突**：PC 和手机各改各的 graph.json，pull 时必然冲突。已加入 .gitignore 并移除追踪。
- **GitHub API token 缺少 `admin:public_key` 作用域**：PC 端无法代加 SSH key，需手机浏览器手动加到 GitHub。

| 操作 | 输入 |
|------|------|
| 拉取最新 | Termux → `sy` |
| 上传改动 | Termux → `ph` |
| 看/写笔记 | Obsidian App 直接打开 |
